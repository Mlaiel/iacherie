## 🛠️ **QUICK START GUIDE**

### ⚡ **1-Minute Setup**
```bash
# Clone the repository
git clone https://github.com/Mlaiel/IA Chérie.git
cd IA Chérie

# Environment setup
cp .env.example .env
# Add your API keys (Hugging Face, OpenAI, etc.)

# Launch the platform
docker-compose up -d    # Full production setup
# OR
python backend_server.py & cd frontend && npm run dev
```
