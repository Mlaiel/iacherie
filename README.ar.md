## 🌟 نظرة عامة

Ainflue هي منصة شاملة مدعومة بالذكاء الاصطناعي لحماية المحتوى وتحقيق الدخل، مصممة خصيصاً للمبدعين والمؤثرين والعلامات التجارية. تجمع المنصة بين تقنيات الذكاء الاصطناعي المتقدمة والأمان القوي والبنية التحتية القابلة للتوسع لتوفير خدمات إدارة وحماية المحتوى على مستوى المؤسسات.

**🚀 آخر التحديثات - توحيد الهندسة المعمارية v4.0.0:**
- **✅ هندسة المؤسسات**: دمج 27 → 15 وحدة أعمال (تقليل 44%)
- **✅ تسمية مهنية**: القضاء على جميع المصطلحات غير المهنية
- **✅ هيكل محسن**: جميع الوحدات تتوافق مع حد أقصى 18 ملف
- **✅ قابلية صيانة محسنة**: تنظيم الكود المحسن وعلاقات الوحدات

## 🚀 البدء السريع

### المتطلبات الأساسية

- Python 3.12+
- Docker & Docker Compose
- Node.js 18+ (للواجهة الأمامية)
- Kubernetes (للإنتاج)

### إعداد التطوير

```bash
# استنساخ المستودع
git clone https://github.com/Mlaiel/Ainflue.git
cd Ainflue

# تثبيت التبعيات
pip install -r requirements.txt

# بدء بيئة التطوير
docker-compose up -d

# تشغيل التطبيق
python main.py
```

## 📊 المراقبة والملاحظة

### 🎯 مجموعة مراقبة كاملة - محسنة

#### مجموعة ELK (Elasticsearch, Logstash, Kibana)
- **تجميع سجلات على مستوى المؤسسة** مع الأمان والاستدامة
- **تحليل السجلات في الوقت الفعلي** عبر جميع الخدمات المصغرة
- **تحليل مخصص للسجلات** لأحداث سير العمل التجاري
- **الموقع**: `kubernetes/monitoring/elk_stack.yaml`

#### مقاييس Prometheus + Grafana
- **جمع المقاييس في الوقت الفعلي** من جميع الخدمات
- **9 لوحات معلومات شاملة** تغطي مقاييس النظام والأعمال والذكاء الاصطناعي
- **تتبع مؤشرات الأداء المخصصة** متوافقة مع مراحل سير العمل
- **الموقع**: `monitoring/prometheus/`, `monitoring/grafana/`

#### 🆕 تتبع أخطاء Sentry
- **تجميع أخطاء ذكي** مع اكتشاف الأنماط
- **إثراء السياق التجاري** (المستخدم، مرحلة سير العمل، الخدمة)
- **تحليل اتجاهات الأخطاء التلقائي** مع رؤى التعلم الآلي
- **تصفية أخطاء ذكية** لتقليل الضوضاء
- **الموقع**: `monitoring/error_tracking/`

#### 🆕 تنبيهات PagerDuty الذكية
- **سياسات تصعيد واعية بالأعمال** على أساس أهمية الخدمة
- **توجيه تنبيهات ذكي** مع تحليل السياق
- **إشعارات متعددة القنوات** (Slack، البريد الإلكتروني، SMS)
- **قمع تنبيهات تلقائي** للمشاكل المعروفة
- **الموقع**: `monitoring/pagerduty_integration/`

#### 🆕 مراقبة سير العمل التجاري
- **تتبع رحلة المستخدم الشامل**: الرفع → الذكاء الاصطناعي → الحماية → تحسين محركات البحث → التعاون → التوزيع
- **اكتشاف اختناقات الوقت الفعلي** مع توصيات التحسين
- **تحليل تأثير الإيرادات** ومقاييس الأعمال
- **رؤى تحسين تجربة المستخدم**
- **الموقع**: `monitoring/business_workflow_dashboards/`

### متغيرات بيئة المراقبة
```bash
# تتبع أخطاء Sentry
SENTRY_DSN=https://your_sentry_dsn@sentry.io/project_id
SENTRY_ENVIRONMENT=production

# تكامل PagerDuty
PAGERDUTY_INTEGRATION_KEY=your_pagerduty_integration_key
PAGERDUTY_API_TOKEN=your_pagerduty_api_token

# إشعارات Slack
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/your/webhook/url
```
