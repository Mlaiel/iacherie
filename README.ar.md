## 🌟 نظرة عامة

أينفلو هي منصة شاملة مدعومة بالذكاء الاصطناعي لحماية المحتوى والاستثمار، مصممة خصيصاً للمبدعين والمؤثرين والعلامات التجارية. تجمع المنصة بين تقنيات الذكاء الاصطناعي المتقدمة والأمان القوي والبنية التحتية القابلة للتطوير لتوفير خدمات إدارة وحماية المحتوى على مستوى المؤسسات.

## 🚀 البدء السريع

### المتطلبات الأساسية

- Python 3.12+
- Docker & Docker Compose
- Node.js 18+ (للواجهة الأمامية)
- Kubernetes (للإنتاج)

### إعداد التطوير

```bash
# استنساخ المستودع
git clone https://github.com/Mlaiel/Ainflue.git
cd Ainflue

# تثبيت التبعيات
pip install -r requirements.txt

# بدء بيئة التطوير
docker-compose up -d

# تشغيل التطبيق
python main.py
```

### نشر الإنتاج

```bash
# النشر على Kubernetes
kubectl apply -f kubernetes/

# نشر مجموعة المراقبة
kubectl apply -f kubernetes/monitoring/

# التحقق من النشر
kubectl get pods -n ainflue
```
