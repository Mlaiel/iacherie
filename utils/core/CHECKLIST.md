### 1. Pattern Result Container

```python
@dataclass
class UtilityResult(Generic[T]):
    success: bool
    data: Optional[T] = None
    errors: List[str] = field(default_factory=list)
    warnings: List[str] = field(default_factory=list)
    metadata: Dict[str, Any] = field(default_factory=dict)
    execution_time_ms: float = 0.0
    timestamp: datetime = field(default_factory=lambda: datetime.now(timezone.utc))
```

### 2. Pattern Configuration Management
```python
class BaseUtilityConfig:
    def __init__(self, config: Dict[str, Any]):
        self.config = config
        self.performance_threshold_ms = config.get('performance_threshold', 10.0)
        self.enable_monitoring = config.get('enable_monitoring', True)
```

### 3. Pattern Performance Monitoring
```python
async def _measure_performance(self, operation: Callable) -> Tuple[Any, float]:
    start_time = time.perf_counter()
    result = await operation()
    execution_time = (time.perf_counter() - start_time) * 1000
    return result, execution_time
```
