## 🚀 Démarrage Rapide

### Installation

```bash
# Cloner le dépôt
git clone https://github.com/Mlaiel/IA Chérie.git
cd IA Chérie/seo/enterprise

# Installer les dépendances
pip install -r requirements-enterprise.txt

# Initialiser les modules entreprise
python -m seo.enterprise.init_enterprise
```

### Configuration de Base

```python
from seo.enterprise import SEOGovernanceFramework

# Initialiser le framework de gouvernance
governance = SEOGovernanceFramework(
    compliance_standards=["RGPD", "CCPA", "SOX"],
    security_level="entreprise",
    monitoring_enabled=True
)

# Démarrer la surveillance entreprise
await governance.start_monitoring()
```

### Variables d'Environnement

```bash

COMPLIANCE_STANDARDS=RGPD,CCPA,SOX
SECURITY_LEVEL=entreprise
MONITORING_ENABLED=true

# Configuration Multi-Locataire
TENANT_ISOLATION=enabled
```
