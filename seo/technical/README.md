## 📚 Usage Examples

### **Basic Technical Analysis**
```python
from seo.technical.technical_innovation_hub import TechnicalInnovationHub

# Initialize the innovation hub
hub = TechnicalInnovationHub()

# Sample data for analysis
crawl_data = {
    'avg_response_time': 1200,
    'error_rate': 0.03,
    'mobile_friendly_ratio': 0.85,
    'schema_coverage': 0.70
}

performance_metrics = {
    'core_web_vitals_score': 75,
    'page_speed_score': 68,
    'seo_score': 82
}

# Perform comprehensive innovation analysis
analysis = await hub.comprehensive_innovation_analysis(
    crawl_data, 
    performance_metrics
)

print(f"Innovation Score: {analysis['innovation_score']['overall_innovation_score']:.2f}")
print(f"Recommendations: {len(analysis['innovation_recommendations'])}")
```

### **Creator-Specific Optimization**
```python
from seo.technical.creator_technical_seo import CreatorTechnicalSEO

# Initialize creator-focused optimization
creator_seo = CreatorTechnicalSEO()

# Creator profile optimization
creator_profile = {
    'creator_type': 'music_artist',
    'platform_focus': ['youtube', 'spotify', 'instagram'],
    'content_types': ['audio', 'video', 'image']
}

# Generate creator-specific technical optimization
optimization = await creator_seo.optimize_for_creator(creator_profile)
```

### **Performance Monitoring Dashboard**
```python
from seo.technical.technical_performance_monitor import TechnicalPerformanceMonitor

# Initialize performance monitoring
monitor = TechnicalPerformanceMonitor()

# Get real-time performance dashboard
dashboard = await monitor.get_performance_dashboard()
print(f"Performance Status: {dashboard['overall_health_status']}")
```
