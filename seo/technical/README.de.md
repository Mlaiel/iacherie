## 📚 Verwendungsbeispiele

### **Grundlegende Technische Analyse**
```python
from seo.technical.technical_innovation_hub import TechnicalInnovationHub

# Innovation Hub initialisieren
hub = TechnicalInnovationHub()

# Beispieldaten für Analyse
crawl_data = {
    'avg_response_time': 1200,
    'error_rate': 0.03,
    'mobile_friendly_ratio': 0.85,
    'schema_coverage': 0.70
}

performance_metrics = {
    'core_web_vitals_score': 75,
    'page_speed_score': 68,
    'seo_score': 82
}

# Umfassende Innovation Analyse durchführen
analysis = await hub.comprehensive_innovation_analysis(
    crawl_data, 
    performance_metrics
)

print(f"Innovation Score: {analysis['innovation_score']['overall_innovation_score']:.2f}")
print(f"Empfehlungen: {len(analysis['innovation_recommendations'])}")
```
