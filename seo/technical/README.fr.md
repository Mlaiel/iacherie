## 📚 Exemples d'Utilisation

### **Analyse Technique de Base**
```python
from seo.technical.technical_innovation_hub import TechnicalInnovationHub

# Initialiser le hub d'innovation
hub = TechnicalInnovationHub()

# Données échantillon pour l'analyse
crawl_data = {
    'avg_response_time': 1200,
    'error_rate': 0.03,
    'mobile_friendly_ratio': 0.85,
    'schema_coverage': 0.70
}

performance_metrics = {
    'core_web_vitals_score': 75,
    'page_speed_score': 68,
    'seo_score': 82
}

# Effectuer une analyse d'innovation complète
analysis = await hub.comprehensive_innovation_analysis(
    crawl_data, 
    performance_metrics
)

print(f"Score Innovation: {analysis['innovation_score']['overall_innovation_score']:.2f}")
print(f"Recommandations: {len(analysis['innovation_recommendations'])}")
```

### **Optimisation Spécifique Créateur**
```python
from seo.technical.creator_technical_seo import CreatorTechnicalSEO

# Initialiser l'optimisation axée créateur
creator_seo = CreatorTechnicalSEO()

# Optimisation profil créateur
creator_profile = {
    'creator_type': 'music_artist',
    'platform_focus': ['youtube', 'spotify', 'instagram'],
    'content_types': ['audio', 'video', 'image']
}

# Générer optimisation technique spécifique créateur
optimization = await creator_seo.optimize_for_creator(creator_profile)
```
