## 🚀 **Schnellstart**

### 1. Schutzsystem initialisieren:
```python
from content_protection import ContentProtectionService

# Service initialisieren
protection = ContentProtectionService()

# Fingerprinting einrichten
await protection.initialize_fingerprinting()
```

### 2. Content schützen:
```python
# Audio-Schutz
audio_fingerprint = await protection.fingerprinting.audio.create_fingerprint(
    file_path="kuenstler_song.mp3",
    user_id=123
)

# Überwachung starten
monitoring_job = await protection.monitoring.start_surveillance(
    fingerprint_id=audio_fingerprint.id,
    platforms=["youtube", "spotify", "soundcloud"]
)
```

### 3. Verstöße behandeln:
```python
# Automatisierte DMCA-Takedown
if violation_detected:
    dmca_request = await protection.dmca_automation.send_takedown_notice(
        violation_id=violation.id,
        platform="youtube"
    )
```
