## API-Verwendungsbeispiele

### Basis-Trendanalyse
```python
from crawlers import MarketIntelligenceCrawler

# Crawler initialisieren
crawler = MarketIntelligenceCrawler(config, platform_apis)

# Aktuelle Trends analysieren
trends = await crawler.analyze_market_trends(
    categories=[MarketCategory.MUSIC, MarketCategory.ENTERTAINMENT],
    platforms=[PlatformType.YOUTUBE, PlatformType.TIKTOK],
    time_range=timedelta(hours=24)
)

# Top-Trending-Content erhalten
top_trends = trends[:10]
for trend in top_trends:
    print(f"Trend: {trend.title}")
    print(f"Wachstumsrate: {trend.growth_rate}")
    print(f"Engagement-Geschwindigkeit: {trend.engagement_velocity}")
```

## Verwendung

### Grundlegende Verwendung

```python
from content_protection.crawlers import MultiPlatformCrawlerService

# Service initialisieren
crawler_service = MultiPlatformCrawlerService(config)
await crawler_service.initialize()

# Plattformübergreifende Suche
results = await crawler_service.search_across_platforms(
    query="Ihre Suchanfrage",
    platforms=["youtube", "tiktok", "instagram"],
    max_results_per_platform=20

# Monitoring starten
await crawler_service.start_continuous_monitoring(
```

## API-Referenz

### MultiPlatformCrawlerService

Hauptservice-Klasse für die Verwaltung aller Plattform-Crawler.

#### Methoden

- `initialize()` - Alle konfigurierten Crawler initialisieren
- `search_across_platforms(query, platforms, max_results_per_platform)` - Content-Suche über mehrere Plattformen
- `start_continuous_monitoring(monitor_id, search_queries, platforms, callback_func)` - Content-Monitoring starten
- `stop_monitoring(monitor_id)` - Monitoring stoppen
- `get_platform_status()` - Status aller Plattformen abrufen
- `health_check()` - Gesundheitscheck durchführen
- `shutdown()` - Service ordnungsgemäß herunterfahren

### Plattform-Crawler

Jede Plattform hat ihren dedizierten Crawler mit spezialisierten Funktionen:

- **YouTubeCrawler**: API + Selenium Hybrid
- **TikTokCrawler**: Anti-Erkennungs-Scraping
- **InstagramCrawler**: Graph API + öffentliches Scraping
- **TwitterCrawler**: API v2 umfassender Zugang
- **GenericWebCrawler**: Universelles Web-Crawling
