# 📄 Système de Gestion des Licences - Documentation Complète

## 🌟 Aperçu

Le **Système de Gestion des Licences** est une plateforme ultra-avancée de licence et de gestion des droits alimentée par l'IA, conçue pour les créateurs de contenu, musiciens, influenceurs et professionnels des médias. Ce système complet automatise la génération de licences, l'enregistrement des droits d'auteur, la distribution des revenus et la surveillance de la conformité dans plusieurs juridictions et plateformes.


2. **Installer les Dépendances**
```bash
# Créer un environnement virtuel
python -m venv venv
source venv/bin/activate  # Linux/Mac
# ou
venv\Scripts\activate     # Windows

# Installer les requirements
pip install -r requirements.txt
```

3. **Configurer l'Environnement**
```bash
# Copier le modèle d'environnement
cp .env.example .env

# Éditer la configuration
nano .env
```

4. **Initialiser la Base de Données**
```bash
# Exécuter les migrations de base de données
python -m alembic upgrade head

# Charger les données initiales
python scripts/seed_licensing_data.py
```

5. **Démarrer les Services**
```bash
# Démarrer le système de licence
python -m uvicorn backend.content_protection.licensing:app --reload
```

## 📖 Exemples d'Utilisation

### Génération de Licence de Base

```python
from backend.content_protection.licensing import LicensingSystem

# Initialiser le système de licence
licensing = LicensingSystem({
    'database_url': 'postgresql://user:pass@localhost/licensing',
    'ai_models_path': './models',
    'blockchain_network': 'ethereum',
    'legal_templates_path': './templates'
})

# Générer une licence automatisée
license_request = {
    'content_type': 'musical_work',
    'territory': ['US', 'EU', 'UK'],
    'usage_rights': ['streaming', 'download', 'public_performance'],
    'revenue_share': 70.0,
    'exclusivity': False,
    'duration': {'years': 5}
}

result = await licensing.generate_automated_license(
    content_id='track_12345',
    parameters=license_request
)

print(f"Licence générée : {result['license_id']}")
```

### Génération de Contrat IA

```python
# Générer un contrat alimenté par l'IA
contract_params = {
    'contract_type': 'music_licensing',
    'jurisdiction': 'eu_general',
    'parties': {
        'licensor': {'name': 'Nom Artiste', 'country': 'France'},
        'licensee': {'name': 'Plateforme SARL', 'country': 'France'}
    },
    'financial_terms': {
        'royalty_percentage': 75.0,
        'minimum_guarantee': 10000.0,
        'currency': 'EUR'
    },
    'content_details': {
        'title': 'Titre Chanson',
        'description': 'Composition musicale originale'
    }
}

contract_result = await licensing.generate_ai_contract(
    contract_parameters=contract_params,
    custom_clauses=['Clause de force majeure', 'Clause d\'arbitrage']
)

print(f"Contrat généré : {contract_result['contract_id']}")
```
