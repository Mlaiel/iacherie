# Module d'Analyse Crawlers

## Système Professionnel d'Analyse de Contenu pour IA-Influencer-Agent

Le **Module d'Analyse Crawlers** est un système d'analyse de contenu avancé de niveau entreprise, conçu pour le traitement complet de contenu multi-modal, la détection de similarité et la protection des droits d'auteur. Ce module est un composant central de la plateforme IA-Influencer-Agent, implémentant des technologies IA de pointe pour les créateurs de contenu et la gestion des droits numériques.

## Exemples d'Usage

### Analyse de Contenu

```python
from crawlers.analysis import ContentAnalyzer, ContentType

# Initialiser l'analyseur
analyzer = ContentAnalyzer(enable_gpu=True)

# Analyser le contenu
result = await analyzer.analyze_content(
    content_id="unique_id",
    content_data="/chemin/vers/contenu",
    content_type=ContentType.IMAGE
)

print(f"Analyse terminée : {result.threat_level}")
print(f"Confiance : {result.confidence_score:.2%}")
```

### Détection de Similarité

```python
from crawlers.analysis import SimilarityDetector, MatchingStrategy

# Initialiser le détecteur
detector = SimilarityDetector(enable_gpu=True)

# Détecter les similarités
matches = await detector.detect_similarity(
    query_content=content_data,
    content_database=database,
    strategy=MatchingStrategy.HYBRID_ANALYSIS
)

for match in matches:
    print(f"Correspondance trouvée : {match.similarity_score.overall_score:.2%}")
```

### Classification de Contenu

```python
from crawlers.analysis import ContentClassifier, ClassificationMethod

# Initialiser le classificateur
classifier = ContentClassifier(enable_gpu=True)

# Classifier le contenu
result = await classifier.classify_content(
    content_id="content_id",
    content_data=data,
    method=ClassificationMethod.DEEP_LEARNING
)

print(f"Catégorie : {result.primary_category}")
print(f"Confiance : {result.confidence:.2%}")
```
