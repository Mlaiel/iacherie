## 📚 **Fortgeschrittene Engine-Dokumentation**

### 🎵 **Musik & Audio-Plattformen**

#### YouTube Music Crawler Engine
```python
from crawlers.engines import YouTubeCrawlerEngine

engine = YouTubeCrawlerEngine(api_key="ihr_api_key")
videos = await engine.search_videos("musik tutorial", max_results=50)
kanal_daten = await engine.get_channel_details("UC_kanal_id")
monetarisierung = await engine.get_monetization_data("video_id")
```

#### Spotify Erweiterte Engine
```python
from crawlers.engines import SpotifyCrawlerEngine

engine = SpotifyCrawlerEngine(client_id="id", client_secret="secret")
tracks = await engine.search_tracks("artist:\"Ed Sheeran\"")
analytik = await engine.get_artist_analytics("spotify:artist:6eUKZXaKkcviH0Ku9w2n3V")
```
