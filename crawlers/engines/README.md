#### YouTube Music Crawler Engine
```python
from crawlers.engines import YouTubeCrawlerEngine

engine = YouTubeCrawlerEngine(api_key="your_api_key")
videos = await engine.search_videos("music tutorial", max_results=50)
channel_data = await engine.get_channel_details("UC_channel_id")
monetization = await engine.get_monetization_data("video_id")
```

#### Spotify Advanced Engine
```python
from crawlers.engines import SpotifyCrawlerEngine
```
