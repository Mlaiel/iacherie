## 📋 Aperçu

Le module `crawlers/adapters` fournit une collection complète de composants d'adaptateurs de niveau industriel pour la plateforme IA-Influencer Agent. Ce système permet une intégration transparente avec plusieurs sources de contenu, plateformes, protocoles et formats de données tout en maintenant des standards de sécurité et de performance de niveau entreprise.

### 🎯 Fonctionnalités Principales

- **Traitement Multi-format** - Analyse audio, vidéo, image, texte, document
- **Intégration Plateforme** - YouTube, Spotify, Instagram, TikTok, Twitter, Facebook, LinkedIn  
- **Communication API** - REST, GraphQL, WebSocket, webhooks, protocoles streaming
- **Systèmes de Stockage** - Base de données, système de fichiers, cloud, cache, vector stores
- **Traitement de Données** - JSON, XML, CSV, binaire, ProtoBuf, MessagePack
- **Support Protocole** - HTTP/HTTPS, WebSocket, FTP/SFTP, TCP/UDP
- **Authentification** - OAuth2, JWT, clés API, certificats, multi-facteur
- **Conversion Format** - Transcodage média, compression, cryptage

## Architecture

Le système d'adaptateurs est construit sur une architecture modulaire avec des adaptateurs spécialisés pour différents besoins d'intégration :

### Composants Principaux

1. **Content Adapters** (`content_adapters.py`)
   - Traitement de contenu audio avec analyse MFCC et spectrale
   - Traitement de contenu vidéo avec extraction et analyse de frames
   - Traitement de contenu image avec hachage perceptuel
   - Traitement de contenu texte avec embeddings BERT
   - Traitement de documents pour formats PDF, DOCX et XLSX

2. **Platform Adapters** (`platform_adapters.py`)
   - Intégration YouTube via API v3
   - Intégration Spotify via spotipy
   - Crawling de contenu Instagram avec instaloader
   - Extraction de contenu TikTok
   - Intégration Twitter/X via tweepy
   - Intégration Facebook Graph API
   - Intégration LinkedIn API

3. **API Adapters** (`api_adapters.py`)
   - Communication API REST avec pagination et logique de retry
   - Traitement de requêtes GraphQL
   - Communication WebSocket en temps réel
   - Gestion d'événements webhook avec vérification de signature
   - Traitement de données en streaming

4. **Storage Adapters** (`storage_adapters.py`)
   - Intégration de base de données (PostgreSQL, MySQL, MongoDB)
   - Opérations système de fichiers avec I/O async
   - Intégration de stockage cloud (compatible S3)
   - Gestion de cache avec Redis
   - Intégration de magasin vectoriel avec FAISS

5. **Data Adapters** (`data_adapters.py`)
   - Traitement JSON avec sérialisation personnalisée
   - Analyse et génération XML
   - Gestion CSV avec auto-détection
   - Traitement de données binaires
   - Sérialisation Protocol Buffer
   - Compression MessagePack

6. **Protocol Adapters** (`protocol_adapters.py`)
   - Communication HTTP/HTTPS
   - Connexions WebSocket sécurisées
   - Transfert de fichiers FTP/SFTP
   - Communication socket TCP brute

7. **Authentication Adapters** (`authentication_adapters.py`)
   - Flux d'authentification OAuth2
   - Génération et validation de tokens JWT
   - Gestion de clés API
   - Authentification HTTP basique
   - Authentification basée sur certificat

8. **Format Adapters** (`format_adapters.py`)
   - Traitement de formats média (images, vidéos, audio)
   - Compression et décompression de données
   - Chiffrement et déchiffrement
   - Sérialisation de données
   - Validation de schéma

from backend.crawlers.adapters import AdapterManager
from backend.crawlers.adapters.content_adapters import AudioContentAdapter

# Initialiser le gestionnaire d'adaptateurs
adapter_manager = AdapterManager()

audio_adapter = AudioContentAdapter()
result = await audio_adapter.process(audio_data)

if result.success:
    fingerprint = result.fingerprint
    features = result.features

### Intégration de Plateforme

```python
from backend.crawlers.adapters.platform_adapters import YouTubeAdapter
from backend.crawlers.adapters import AuthConfig

# Configurer l'API YouTube
auth_config = AuthConfig(
    auth_type="api_key",
    api_key="votre_cle_api_youtube"
)

youtube_adapter = YouTubeAdapter(auth_config)
await youtube_adapter.initialize()

# Rechercher du contenu
results = await youtube_adapter.search_content(
    query="vos_termes_de_recherche",
    max_results=50
)
```

## Optimisation des Performances

### Pool de Connexions

Tous les adaptateurs implémentent le pool de connexions pour minimiser la surcharge :

- **HTTP/HTTPS** : aiohttp.TCPConnector avec tailles de pool configurables
- **Base de Données** : Pools de connexions avec mise à l'échelle automatique
- **Redis** : Pool de connexions avec vérifications de santé
- **WebSocket** : Connexions persistantes avec reconnexion automatique

### Stratégie de Cache

- **Empreintes de Contenu** : Cache LRU pour le contenu récemment traité
- **Réponses API** : Cache TTL configurable pour les données de plateforme
- **Tokens d'Authentification** : Actualisation automatique des tokens et cache
- **Métadonnées** : Cache basé sur Redis pour les données fréquemment accédées

## Considérations de Sécurité

### Protection des Données

- **Chiffrement au Repos** : Toutes les données sensibles chiffrées avec Fernet ou AES-256
- **Chiffrement en Transit** : TLS 1.3 pour toutes les communications externes
- **Contrôle d'Accès** : Accès basé sur les rôles avec tokens JWT
- **Logging d'Audit** : Logging complet de toutes les opérations

### Sécurité API

- **Limitation de Débit** : Limites de débit configurables pour tous les endpoints API
- **Authentification** : Support pour OAuth2, clés API et authentification par certificat
- **Validation d'Entrée** : Sanitisation et validation d'entrée complètes
- **Protection CORS** : Politiques CORS configurables
