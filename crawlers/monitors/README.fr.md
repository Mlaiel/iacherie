## 📋 Installation & Configuration

### Exigences
- Python 3.9 ou supérieur
- PostgreSQL 12+ pour stockage persistant
- Redis 6+ pour cache et files d'attente
- Accès réseau aux plateformes surveillées

### Démarrage Rapide
```bash
# Installer les dépendances
pip install -r requirements.txt

# Configurer les paramètres de surveillance
cp config/monitoring.yml.example config/monitoring.yml

# Initialiser le système de surveillance
python -m backend.crawlers.monitors

# Démarrer les services de surveillance
python scripts/monitoring/start_monitoring.py
```

## 🔍 Exemples d'Utilisation

### Configuration de Base de Surveillance
```python
from backend.crawlers.monitors import MonitoringOrchestrator
from backend.crawlers.monitors.monitor_engine import MonitoringConfiguration

# Configurer la surveillance
config = MonitoringConfiguration(
    monitoring_interval=60,
    alert_thresholds={
        "cpu_usage": 80,
        "memory_usage": 85,
        "disk_usage": 90
    }
)

# Initialiser et démarrer la surveillance
orchestrator = MonitoringOrchestrator(config)
await orchestrator.initialize()
await orchestrator.start_monitoring()
```

### Règles de Sécurité Personnalisées
```python
from backend.crawlers.monitors.security_monitor import SecurityMonitor

# Créer moniteur de sécurité avec règles personnalisées
security_monitor = SecurityMonitor(config)
await security_monitor.add_security_rule({
    "name": "suspicious_login_pattern",
    "threshold": 5,
    "window_minutes": 10,
    "action": "block_ip"
})
```
