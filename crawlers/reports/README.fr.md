## 📊 Exemples d'Utilisation

### Génération de Rapport de Base
```python
from reports.generators import PerformanceReportGenerator
from reports.formatters import PDFFormatter
from reports.exporters import EmailExporter

# Initialiser les composants
generator = PerformanceReportGenerator()
formatter = PDFFormatter()
exporter = EmailExporter()

# Générer rapport de performance
report_data = await generator.generate_report(
    platform_id="instagram",
    date_range="last_30_days",
    metrics=['engagement', 'reach', 'conversion']
)

# Formater en PDF professionnel
pdf_result = await formatter.format_report(
    report_data,
    template_style="corporate",
    include_charts=True
)

# Envoyer par email aux dirigeants
await exporter.export_report(
    pdf_result,
    destination="executives@company.com",
    subject="Rapport Performance Mensuel"
)
```

### Pipeline d'Analytique Avancé
```python
from reports.analytics import PerformanceAnalyticsEngine
from reports.processors import MetricsProcessor
from reports.visualizers import DashboardVisualizer

# Créer pipeline analytique
analytics = PerformanceAnalyticsEngine()
processor = MetricsProcessor()
visualizer = DashboardVisualizer()

# Traiter données avec insights ML
analytics_result = await analytics.analyze_performance(
    data=platform_data,
    include_predictions=True,
    anomaly_detection=True
)

# Calculer métriques complètes
metrics_result = await processor.process(
    analytics_result.data,
    context={'targets': performance_targets}
)

# Générer tableau de bord interactif
dashboard = await visualizer.create_dashboard(
    metrics_result.metrics,
    chart_types=['trend', 'comparison', 'distribution'],
    interactive=True
)
```

## 📚 Documentation API
