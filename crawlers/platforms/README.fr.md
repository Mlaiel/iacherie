### 🔧 Configuration

```yaml
# Exemple de configuration
platforms:
  youtube:
    api_key: ${YOUTUBE_API_KEY}
    rate_limit: 10000/day
    batch_size: 50
  
  instagram:
    access_token: ${INSTAGRAM_ACCESS_TOKEN}
    rate_limit: 200/hour
    
  generic:
    user_agents: rotating
    proxy_enabled: true
    delay_range: [1, 3]
```

### 🚦 Utilisation

```python
from backend.crawlers.platforms import YouTubeCrawler, InstagramCrawler

# Surveiller contenu YouTube
youtube = YouTubeCrawler(api_key="your_key")
results = await youtube.search_content("your_search_query")

# Surveiller profils Instagram
instagram = InstagramCrawler(access_token="token")
profile_data = await instagram.get_profile_data("username")
```
