## 🚀 Schnellstart

### Grundlegende Verwendung

```python
import asyncio
from IA_Influencer_Agent.backend.crawlers.workers import (
    initialize_workers,
    get_task_orchestrator,
    WorkflowDefinition,
    TaskDefinition,
    TaskType,
    ExecutionStrategy
)

async def main():
    # Worker-System initialisieren
    config = {
        "enable_all_components": True,
        "redis_url": "redis://localhost:6379",
        "max_workers": 10
    }
    
    success = await initialize_workers(config)
    if not success:
        print("Fehler beim Initialisieren der Worker")
        return
    
    # Task-Orchestrator abrufen
    orchestrator = get_task_orchestrator()
    
    # Workflow definieren
    workflow = WorkflowDefinition(
        workflow_id="content_processing_workflow",
        name="Content Processing Pipeline",
        description="Verarbeitung von Social Media Content mit Schutz",
        tasks=[
            TaskDefinition(
                task_id="crawl_content",
                task_type=TaskType.CRAWLER_TASK,
                task_config={
                    "target_url": "https://example.com/content",
                    "platform": "web",
                    "content_types": ["text", "image"]
                }
            ),
            TaskDefinition(
                task_id="generate_fingerprint",
                task_type=TaskType.FINGERPRINT_TASK,
                task_config={
                    "content_items": ["${crawl_content.result.items}"]
                },
                dependencies=["crawl_content"]
            )
        ],
        execution_strategy=ExecutionStrategy.DAG
    )
    
    # Workflow registrieren und ausführen
    await orchestrator.register_workflow(workflow)
    execution_id = await orchestrator.execute_workflow(
        workflow.workflow_id,
        {"user_id": "user123", "priority": "high"}
    )
    
    print(f"Workflow gestartet: {execution_id}")

if __name__ == "__main__":
    asyncio.run(main())
```

## 🔧 Fehlerbehebung

### Häufige Probleme

#### Hoher Speicherverbrauch
**Symptome**: Worker verbrauchen übermäßig viel Speicher
**Lösung**: Worker-Speicherlimits anpassen und Garbage Collection aktivieren

#### Queue-Rückstau
**Symptome**: Tasks sammeln sich in der Queue an
**Lösung**: Worker hochskalieren und Verarbeitungsparallelität erhöhen

#### Verbindungs-Timeouts
**Symptome**: Redis-Verbindungs-Timeouts
**Lösung**: Connection-Pooling und Retry-Konfiguration anpassen
