## Architecture
- Base: base.BaseAgent
  - Métriques (Prometheus), rate limiting, circuit breaker, async, hooks sécurité
- Orchestration globale: agent_manager.AgentManager
  - Pools, load‑balancing, routage, santé/récupération, scaling dynamique
- Pipeline métier: content_agent/business_workflow.BusinessWorkflowOrchestrator
  - Orchestre le flux bout‑à‑bout
- Agents cœur: content, protection, seo, collaboration, distribution, monetization
- Agents support: analytics, moderation, recommendation, social_media, support
- Protection: fingerprinting (audio/vidéo/image/texte), similarity matching, watermarking, web monitoring

Points clés du répertoire
- base.py — base entreprise et contrats requête/réponse
- agent_manager.py — pooling, scaling, routage, santé, agrégation métriques
- index.py — API publique (bootstrap/shutdown/route/workflows)
- content_agent/ — analyse, processing, orchestration métier
- protection_agent/ — fingerprinting, watermarking, enforcement des droits
- seo_agent/, collaboration_agent/, distribution_agent/, monetization_agent/ — piliers métier
- fingerprinting_agent/, web_monitoring_agent/ — protection et surveillance avancées

## API publique (index.py)
Bootstrap
```python
from IA_Influencer_Agent.backend.ai_agents.index import bootstrap
ok = await bootstrap()
```

Router une requête
```python
from IA_Influencer_Agent.backend.ai_agents.index import route_request
from IA_Influencer_Agent.backend.ai_agents.base import AgentRequest, AgentPriority

resp = await route_request(AgentRequest(
    user_id="creator_123",
    action="process_upload",
    data={"content_id": "cnt_001", "content_type": "audio", "file_path": "/data/in/song.wav"},
    priority=AgentPriority.HIGH,
))
```

Flux bout‑à‑bout
```python
from IA_Influencer_Agent.backend.ai_agents.index import process_upload
from IA_Influencer_Agent.backend.ai_agents.content_agent.business_workflow import CreatorType

workflow_id = await process_upload(
    content_id="cnt_001",
    creator_id="creator_123",
    creator_type=CreatorType.MUSICIAN,
    content_type="audio",
    file_path="/data/in/song.wav",
    metadata={"target_platforms": ["spotify", "youtube"]},
)
```

Statut système
```python
from IA_Influencer_Agent.backend.ai_agents.index import get_system_status
status = await get_system_status()
```

## Configuration
Pilotée par core.config.settings. Paramètres clés :
- Redis (utilisé par BaseAgent) :
  - REDIS_HOST, REDIS_PORT, REDIS_PASSWORD
- Session base de données (get_db_session) configurée dans core.database
- Pools du Manager (min/max instances, stratégie) ajustables par code ou settings
- Timeouts et limites : timeout requête, rate limiter, seuils du circuit breaker (par agent)

Secrets via variables d’environnement ou coffre‑forts ; ne jamais hardcoder.
