# 🤖 Système de Gestion de Dialogue Enterprise - Plateforme IA Influencer Agent

## 🎯 Aperçu

Le Système de Gestion de Dialogue Enterprise est un framework d'IA conversationnelle sophistiqué et prêt pour la production, conçu spécifiquement pour les créateurs de contenu de la plateforme IA Influencer Agent. Il orchestre des conversations multi-tours complexes, gère des workflows business complets, et fournit des conseils intelligents pour la protection de contenu, l'optimisation de monétisation, la facilitation de collaboration, et l'intégration multi-plateforme.

## 🏗️ Architecture Enterprise

### Composants Principaux

#### 🧠 Orchestration de Dialogue Avancée
- **DialogueFlowManager**: Gestion principale des flux de conversation avec orchestration workflow business
- **ConversationOrchestrator**: Coordination enterprise de conversations multi-parties et automatisation

## 🚀 Démarrage

### Prérequis
- Python 3.11+
- PostgreSQL 14+
- Redis 6+
- Configuration worker Celery

### Installation
```bash
# Cloner repository (utilisateurs autorisés seulement)
git clone https://github.com/Mlaiel/IA-influencer.git

# Installer dépendances
pip install -r requirements.txt

# Configurer environnement
cp .env.example .env
# Éditer .env avec votre configuration

# Exécuter migrations de base de données
alembic upgrade head

# Démarrer services
python -m backend.app.main
```

### Configuration
```python
from backend.conversational.dialogue_management import DialogueFlowManager

# Initialiser système de dialogue
dialogue_manager = DialogueFlowManager(
    database_url="postgresql://user:pass@localhost/db",
    redis_url="redis://localhost:6379",
    ai_models_config="config/ai_models.yaml"
)
```
