2. **Translation Engine** (`translation_engine.py`)

## Usage Examples

### Basic Initialization

```python
from multilingual_support import MultilingualOrchestrator, SupportedLanguage

# Initialize the orchestrator
orchestrator = MultilingualOrchestrator(
    language_manager=language_manager,
    translation_engine=translation_engine,
    cultural_adaptor=cultural_adaptor,
    conversation_localizer=conversation_localizer,
    localization_processor=localization_processor,
    redis_client=redis_client,
    db_session=db_session
)

# Initialize multilingual conversation
session, contexts = await orchestrator.initialize_multilingual_conversation(
    user_id="user123",
    primary_language=SupportedLanguage.ENGLISH,
    target_languages=[SupportedLanguage.SPANISH, SupportedLanguage.FRENCH],
    domain="business"
)
```

### Processing Messages

```python
# Process a multilingual message
response = await orchestrator.process_multilingual_message(
    message="Hello, how are you today?",
    session_id=session.session_id,
    target_language=SupportedLanguage.SPANISH,
    message_type=MessageType.USER_MESSAGE
)

print(f"Original: {response.original_message}")
print(f"Localized: {response.processed_message.localized_text}")
print(f"Confidence: {response.processed_message.confidence_score}")
```

### Language Switching

```python
# Switch conversation language
success = await orchestrator.switch_conversation_language(
    session_id=session.session_id,
    new_target_language=SupportedLanguage.GERMAN,
    switch_reason="user_preference"
)
```

### Cultural Adaptation

```python
# Apply cultural adaptation
adaptation_result = await cultural_adaptor.adapt_message_culturally(
    message="Let's schedule a meeting for tomorrow",
    source_culture="US",
    target_culture="JP",
    business_context=True
)
```

### Advanced Localization

```python
# Localize specific content types
from datetime import datetime

# Date/time localization
datetime_request = LocalizationRequest(
    content=datetime.now(),
    content_type=ContentType.DATETIME,
    target_language=SupportedLanguage.GERMAN,
    cultural_context=cultural_context

result = await localization_processor.process_localization_request(datetime_request)
```

## Integration Guide

### Backend Integration

```python
# FastAPI Integration
from fastapi import FastAPI, Depends
from multilingual_support import MultilingualOrchestrator

app = FastAPI()

@app.post("/api/v1/multilingual/process")
async def process_message(
    request: MultilingualMessageRequest,
    orchestrator: MultilingualOrchestrator = Depends(get_orchestrator)
):
    response = await orchestrator.process_multilingual_message(
        message=request.message,
        session_id=request.session_id,
        target_language=request.target_language
    )
    return response
```
