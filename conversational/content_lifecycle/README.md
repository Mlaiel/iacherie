
## 🔍 API Documentation

### Core Endpoints

#### Content Lifecycle Management
```
POST   /api/v1/lifecycle/create              - Create new content lifecycle
GET    /api/v1/lifecycle/{content_id}        - Get lifecycle status
PUT    /api/v1/lifecycle/{content_id}/state  - Update content state
DELETE /api/v1/lifecycle/{content_id}        - Delete content lifecycle
```

#### Workflow Management
```
POST   /api/v1/workflows/execute             - Execute workflow
GET    /api/v1/workflows/{workflow_id}       - Get workflow status
PUT    /api/v1/workflows/{workflow_id}/pause - Pause workflow execution
```

#### Analytics and Reporting
```
GET    /api/v1/analytics/reports             - Get analytics reports
POST   /api/v1/analytics/insights            - Generate insights
GET    /api/v1/analytics/metrics             - Get performance metrics
```
