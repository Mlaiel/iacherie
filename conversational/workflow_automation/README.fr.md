## 🔧 Exemples d'Utilisation

### Exécution de Workflow de Base
```python
from workflow_automation import WorkflowAutomationOrchestrator

# Initialiser l'orchestrateur
orchestrator = WorkflowAutomationOrchestrator()

# Exécuter workflow de contenu
result = await orchestrator.execute_content_workflow(
    creator_data={
        "creator_id": "creator_123",
        "creator_type": "musician",
        "content_type": "audio"
    },
    content_data={
        "file_path": "/path/to/audio.mp3",
        "metadata": {"title": "Nouvelle Chanson", "genre": "Electronic"}
    },
    workflow_config={
        "protection_enabled": True,
        "monetization_enabled": True,
        "distribution_platforms": ["spotify", "youtube", "instagram"]
    }
)
```

### Automatisation d'Intégration de Créateur
```python
from workflow_automation import CreatorOnboardingWorkflow

# Initialiser workflow d'intégration
onboarding = CreatorOnboardingWorkflow()

# Exécuter intégration complète
result = await onboarding.execute_onboarding_workflow({
    "creator_id": "new_creator_456",
    "email": "creator@example.com",
    "creator_type": "photographer",
    "social_profiles": [
        {"platform": "instagram", "username": "@photographer"}
    ]
})
```

### Optimisation des Revenus
```python
from workflow_automation import RevenueOptimizationEngine

# Initialiser optimiseur de revenus
optimizer = RevenueOptimizationEngine()
```

## 🚀 Démarrage Rapide

### Prérequis
- Python 3.9+
- Redis pour le cache
- PostgreSQL pour le stockage de données
- Celery pour la file d'attente de tâches

### Installation
```bash
# Installer les dépendances
pip install -r requirements.txt

# Initialiser la base de données
python manage.py migrate

# Démarrer les workers Celery
celery -A workflow_automation worker --loglevel=info

# Démarrer les services d'automatisation
python -m workflow_automation.index
```

### Configuration
```python
# Configurer les paramètres d'automatisation
WORKFLOW_AUTOMATION_CONFIG = {
    "max_concurrent_workflows": 100,
    "default_timeout": 300,
    "performance_optimization": True,
    "monitoring_enabled": True
}
```
