## 🔧 Usage Examples

### Basic Workflow Execution
```python
from workflow_automation import WorkflowAutomationOrchestrator

# Initialize orchestrator
orchestrator = WorkflowAutomationOrchestrator()

# Execute content workflow
result = await orchestrator.execute_content_workflow(
    creator_data={
        "creator_id": "creator_123",
        "creator_type": "musician",
        "content_type": "audio"
    },
    content_data={
        "file_path": "/path/to/audio.mp3",
        "metadata": {"title": "New Song", "genre": "Electronic"}
    },
    workflow_config={
        "protection_enabled": True,
        "monetization_enabled": True,
        "distribution_platforms": ["spotify", "youtube", "instagram"]
    }
)
```

### Creator Onboarding Automation
```python
from workflow_automation import CreatorOnboardingWorkflow

# Initialize onboarding workflow
onboarding = CreatorOnboardingWorkflow()

result = await onboarding.execute_onboarding_workflow({

    "email": "creator@example.com",
    "creator_type": "photographer",
    "social_profiles": [
        {"platform": "instagram", "username": "@photographer"}
    ]
})
```

## 🚀 Getting Started

### Prerequisites
- Python 3.9+
- Redis for caching
- PostgreSQL for data storage
- Celery for task queuing

### Installation
```bash
# Install dependencies
pip install -r requirements.txt

# Initialize database
python manage.py migrate

# Start Celery workers
celery -A workflow_automation worker --loglevel=info

# Start automation services
python -m workflow_automation.index
```

### Configuration
```python
# Configure automation settings
WORKFLOW_AUTOMATION_CONFIG = {
    "max_concurrent_workflows": 100,
    "default_timeout": 300,
    "performance_optimization": True,
    "monitoring_enabled": True
}
```
