## 🔧 Installation & Configuration

### Prérequis :
```bash
Python 3.11+
Docker & Kubernetes pour Production
Redis pour Cache
PostgreSQL pour Persistance de Données
```

### Configuration Environnement de Développement :
```bash
# Installer dépendances
pip install -r requirements.txt

# Configurer variables d'environnement
cp .env.example .env

# Initialiser base de données
python -m backend.database.init_db

# Démarrer système d'intelligence
python -m backend.conversational.intelligence_algorithms.index
```

### Déploiement Production :
```bash
# Créer container Docker
docker build -t ia-influencer-intelligence .

# Déploiement Kubernetes
kubectl apply -f k8s/intelligence-deployment.yaml

# Vérification santé
curl http://localhost:8000/health/intelligence
```
