## 🛠️ أمثلة الاستخدام

### استعلام التحليلات الأساسي
```python
from distribution.analytics import AnalyticsAggregator

# تهيئة محرك التحليلات
analytics = AnalyticsAggregator()

# الحصول على بيانات أداء المنصة
performance = analytics.get_platform_performance(
    platforms=['instagram', 'tiktok', 'youtube'],
    timeframe='7d',
    metrics=['reach', 'engagement', 'conversions']
)

# تحليل النتائج
for platform, data in performance.items():
    print(f"{platform}: {data['engagement_rate']:.2%} مشاركة")
```

### تحليل الإسناد
```python
from distribution.analytics import AttributionAnalytics

# تهيئة محرك الإسناد
attribution = AttributionAnalytics()

# تحليل رحلة العميل
journey = attribution.analyze_customer_journey(
    customer_id='user123',
    conversion_event='purchase',
    lookback_window=30
)

# الحصول على أوزان الإسناد
weights = attribution.get_attribution_weights(journey)
print(f"المنصة الأكثر مساهمة: {weights[0]['platform']}")
```

## 🔄 التكامل مع سير عمل Ainflue

يعمل هذا الوحدة كـ **العمود الفقري للتحليلات** لسير عمل التوزيع الكامل لـ Ainflue:
