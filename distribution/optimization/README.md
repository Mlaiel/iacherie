## 🛠️ Usage Examples

### AI-Powered Content Optimization
```python
from distribution.optimization import AIOptimizationEngine

# Initialize AI optimization engine
ai_optimizer = AIOptimizationEngine()

# Optimize content for maximum engagement
optimized_content = await ai_optimizer.optimize_content(
    content_data={
        "title": "Original Title",
        "description": "Original description",
        "tags": ["tag1", "tag2"],
        "target_platforms": ["instagram", "tiktok"]
    },
    optimization_goals=["engagement", "reach", "virality"]
)

print(f"Optimized title: {optimized_content['title']}")
print(f"Expected engagement increase: {optimized_content['performance_prediction']['engagement_lift']:.2%}")
```

### Performance Optimization
```python
from distribution.optimization import PerformanceOptimizer

# Initialize performance optimizer
perf_optimizer = PerformanceOptimizer()

# Analyze and optimize system performance
performance_analysis = await perf_optimizer.analyze_performance(
    timeframe="7d",
    metrics=["response_time", "throughput", "error_rate"]
)

# Apply optimization recommendations
optimization_result = await perf_optimizer.apply_optimizations(
    recommendations=performance_analysis["recommendations"]
)
```

### Revenue Optimization
```python
from distribution.optimization import CostOptimizer

# Initialize cost optimizer
cost_optimizer = CostOptimizer()

# Optimize budget allocation across platforms
allocation_strategy = await cost_optimizer.optimize_budget_allocation(
    total_budget=10000,
    platforms=["instagram", "tiktok", "youtube"],
    objectives=["reach", "engagement", "conversions"],
    time_horizon="30d"
)

print(f"Optimal allocation: {allocation_strategy['allocation']}")
print(f"Expected ROI: {allocation_strategy['expected_roi']:.2f}x")
```
