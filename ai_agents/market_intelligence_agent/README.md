## 🔧 Installation & Setup

### Prerequisites
```bash
Python 3.9+
PostgreSQL 13+
Redis 6+
MongoDB 5+
```

### Installation
```bash
# Install dependencies
pip install -r requirements.txt

# Initialize databases
python scripts/setup_databases.py

# Run market intelligence agent
python -m backend.ai_agents.market_intelligence_agent
```
