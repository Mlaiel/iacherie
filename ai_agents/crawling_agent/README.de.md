```python

# Agent initialisieren
agent = CrawlingAgent()
await agent.initialize()

# Überwachungsziel erstellen
target_config = {
    'content_fingerprints': ['fingerprint_hash'],
    'keywords': ['marken_name', 'produkt_name'],

    'alert_types': ['email', 'webhook']
}

target_id = await agent.setup_surveillance(target_config)
```

## API-Referenz

### CrawlingAgent Methoden
- `crawl_website(url, max_depth, content_types)`: Umfassendes Website-Crawling
- `monitor_content(data)`: Content-Überwachung plattformübergreifend
- `search_similar(content, platforms, threshold)`: Ähnlichkeitssuche
- `platform_scan(platforms, scan_type, filters)`: Plattform-spezifisches Scanning
- `surveillance_setup(config)`: Überwachungsziel-Erstellung
- `bulk_crawl(urls, max_concurrent)`: Bulk-URL-Verarbeitung
- `real_time_monitor(config, duration)`: Echtzeit-Überwachung
