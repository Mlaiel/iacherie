### Basic Usage
```python
from crawling_agent import CrawlingAgent

# Initialize agent
agent = CrawlingAgent()
await agent.initialize()

# Create surveillance target
target_config = {
    'content_fingerprints': ['fingerprint_hash'],
    'keywords': ['brand_name', 'product_name'],
    'platforms': ['twitter', 'youtube', 'instagram'],
    'similarity_threshold': 0.8,
    'alert_types': ['email', 'webhook']
}

target_id = await agent.setup_surveillance(target_config)

# Monitor content
results = await agent.monitor_content({
    'content_fingerprint': 'protected_content_hash',
    'platforms': ['twitter', 'youtube'],
    'keywords': ['search_terms']
})
```

## API Reference

### CrawlingAgent Methods
- `crawl_website(url, max_depth, content_types)`: Comprehensive website crawling
- `monitor_content(data)`: Content monitoring across platforms
- `search_similar(content, platforms, threshold)`: Similarity search
- `platform_scan(platforms, scan_type, filters)`: Platform-specific scanning
- `surveillance_setup(config)`: Surveillance target creation
- `bulk_crawl(urls, max_concurrent)`: Bulk URL processing
- `real_time_monitor(config, duration)`: Real-time monitoring

### WebCrawler Methods
- `crawl_url(url, **kwargs)`: Single URL crawling
- `crawl_multiple(urls, max_concurrent)`: Batch URL processing
- `crawl_sitemap(sitemap_url)`: Sitemap-based crawling

### ContentDetector Methods
- `create_content_signature(content, content_type)`: Content fingerprinting
- `calculate_similarity(id1, id2, method)`: Similarity calculation
- `find_similar_content(query_id, max_results)`: Content search

### PlatformCrawler Methods
- `crawl_platform(platform, query, max_results)`: Platform crawling
- `get_user_content(platform, user_id)`: User content extraction
- `search_hashtag(platform, hashtag)`: Hashtag-based search

### SurveillanceEngine Methods
- `create_surveillance_target(config)`: Target setup
- `start_monitoring(target_id)`: Monitoring activation
- `stop_surveillance_target(target_id)`: Target deactivation
