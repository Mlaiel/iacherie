## 🚀 Démarrage Rapide

### Installation
```bash
# Installer les dépendances
pip install -r requirements.txt

# Configurer la base de données
python manage.py migrate

# Configurer l'environnement
cp .env.example .env
# Éditer .env avec votre configuration

# Démarrer l'agent marché
python -m marketplace_agent.main
```

### Utilisation de Base
```python
from marketplace_agent import MarketplaceAgent

# Initialiser l'agent marché
agent = MarketplaceAgent()

# Créer un listing marché
listing = agent.create_listing(
    creator_id=user_id,
    title="Piste Musicale Premium",
    content_type="audio",
    price_model="fixed",
    base_price=29.99
)

# Traiter une demande de collaboration
collaboration = agent.process_collaboration_request(
    requester_id=requester_id,
    target_creator_id=creator_id,
    project_description="Projet de chanson collaborative"
)

# Générer des analytics marché
analytics = agent.generate_marketplace_analytics(
    time_range="30d",
    creator_id=creator_id
)
```

## 🔌 Points de Terminaison API

### Gestion du Marché
```
POST   /api/v1/marketplace/listings          # Créer nouveau listing
GET    /api/v1/marketplace/listings          # Obtenir listings avec filtres
PUT    /api/v1/marketplace/listings/{id}     # Mettre à jour listing
DELETE /api/v1/marketplace/listings/{id}     # Supprimer listing

GET    /api/v1/marketplace/search            # Recherche avancée avec IA
GET    /api/v1/marketplace/categories        # Obtenir catégories marché
GET    /api/v1/marketplace/trending          # Obtenir contenu tendance
```

### Gestion de Collaboration
```
POST   /api/v1/collaboration/requests        # Créer demande collaboration
GET    /api/v1/collaboration/requests        # Obtenir demandes collaboration
PUT    /api/v1/collaboration/requests/{id}   # Mettre à jour statut demande
GET    /api/v1/collaboration/matches         # Correspondance créateur alimentée par IA
```
