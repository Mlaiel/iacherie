## 🚀 Schnellstart

### Installation
```bash
# Abhängigkeiten installieren
pip install -r requirements.txt

# Datenbank einrichten
python manage.py migrate

# Umgebung konfigurieren
cp .env.example .env
# .env mit Ihrer Konfiguration bearbeiten

# Marktplatz-Agent starten
python -m marketplace_agent.main
```

### Grundlegende Verwendung
```python
from marketplace_agent import MarketplaceAgent

# Marktplatz-Agent initialisieren
agent = MarketplaceAgent()

# Marktplatz-Listing erstellen
listing = agent.create_listing(
    creator_id=user_id,
    title="Premium Musik Track",
    content_type="audio",
    price_model="fixed",
    base_price=29.99
)

# Kollaborationsanfrage verarbeiten
collaboration = agent.process_collaboration_request(
    requester_id=requester_id,
    target_creator_id=creator_id,
    project_description="Kollaboratives Song-Projekt"
)

# Marktplatz-Analytics generieren
analytics = agent.generate_marketplace_analytics(
    time_range="30d",
    creator_id=creator_id
)
```

## 🔌 API-Endpunkte

### Marktplatz-Management
```
POST   /api/v1/marketplace/listings          # Neues Listing erstellen
GET    /api/v1/marketplace/listings          # Listings mit Filtern abrufen
PUT    /api/v1/marketplace/listings/{id}     # Listing aktualisieren
DELETE /api/v1/marketplace/listings/{id}     # Listing entfernen

GET    /api/v1/marketplace/search            # Erweiterte Suche mit KI
GET    /api/v1/marketplace/categories        # Marktplatz-Kategorien abrufen
GET    /api/v1/marketplace/trending          # Trending Content abrufen
```

### Kollaborations-Management
```
POST   /api/v1/collaboration/requests        # Kollaborationsanfrage erstellen
GET    /api/v1/collaboration/requests        # Kollaborationsanfragen abrufen
PUT    /api/v1/collaboration/requests/{id}   # Anfrage-Status aktualisieren
GET    /api/v1/collaboration/matches         # KI-gestütztes Creator-Matching
```
