## 🚀 Quick Start

### Installation
```bash
# Install dependencies
pip install -r requirements.txt

# Initialize audio agent
from backend.ai_agents.audio_agent import AudioAgent

# Create agent instance
audio_agent = AudioAgent("main_audio_agent")
await audio_agent.initialize()
```

### Basic Usage

#### Audio Analysis
```python
from backend.ai_agents.audio_agent import AudioProcessor, AudioProcessingRequest

processor = AudioProcessor()

# Analyze audio file
request = AudioProcessingRequest(
    audio_file_path="path/to/audio.wav",
    processing_type="analyze"
)

result = await processor.process_audio_comprehensive(
    audio_data, sample_rate
)
```

#### AI Audio Generation
```python
from backend.ai_agents.audio_agent import AIAudioGenerator, AudioGenerationRequest

generator = AIAudioGenerator()

# Generate audio from text
request = AudioGenerationRequest(
    text_prompt="Uplifting electronic music with energetic beats",
    duration_seconds=30.0,
    genre="electronic",
    mood="energetic"
)

result = await generator.generate_audio(request)
```

#### Audio Enhancement
```python
from backend.ai_agents.audio_agent import AudioEnhancer, EnhancementConfig

enhancer = AudioEnhancer()

# Enhance audio quality
config = EnhancementConfig(
    noise_reduction_strength=0.7,
    quality_level="high",
    use_ai_enhancement=True
)

result = await enhancer.enhance_audio_comprehensive(
    audio_data, sample_rate, config
)
```
