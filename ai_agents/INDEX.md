## 🚀 Quick Start Guide

### 1. Installation & Setup
```bash
# Clone the repository
git clone [repository-url]
cd IA-Influencer-Agent

# Install dependencies
pip install -r backend/requirements.txt

# Configure environment
cp .env.example .env
# Edit .env with your API keys and settings
```

### 2. Initialize Agent System
```python
from backend.ai_agents import initialize_agent_system

async def main():
    success = await initialize_agent_system()
    if success:
        print("✅ All agents initialized successfully")
    else:
        print("❌ Agent initialization failed")
```

### 3. Basic Usage Examples

#### Content Processing
```python
from backend.ai_agents import AgentFactory, AgentRequest

# Create content agent
content_agent = await AgentFactory.create_agent("content_agent", "content_001")

# Process content
request = AgentRequest(
    action="analyze_content",
    data={
        "content_type": "audio",
        "file_path": "/path/to/audio.mp3",
        "analysis_types": ["metadata", "quality", "genre"]
    }
)

response = await content_agent.process_request(request)
```

#### Analytics Generation
```python
# Create analytics agent
analytics_agent = await AgentFactory.create_agent("analytics_agent", "analytics_001")

# Generate report
request = AgentRequest(
    action="generate_analytics_report",
    data={
        "user_id": "creator123",
        "date_range": {"start": "2024-01-01", "end": "2024-12-31"},
        "platforms": ["spotify", "youtube", "instagram"]
    }
)

response = await analytics_agent.process_request(request)
```
