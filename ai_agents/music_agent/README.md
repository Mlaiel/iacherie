## 🚀 Getting Started

### **Prerequisites**
- Python 3.9+
- PostgreSQL 13+
- Redis 6.0+
- Elasticsearch 7.14+
- Spotify Developer Account

### **Installation**
```bash
# Clone repository (authorized users only)
git clone https://github.com/authorized/music-agent.git
cd music-agent

# Install dependencies
pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Edit .env with your credentials

# Initialize database
python manage.py migrate

# Start services
python manage.py runserver
```

### **Configuration**
```python
# settings.py
MUSIC_AGENT_CONFIG = {
    'spotify_client_id': 'your_spotify_client_id',
    'spotify_client_secret': 'your_spotify_client_secret',
    'ai_models_path': '/path/to/ai/models',
    'cache_backend': 'redis://localhost:6379/1'
}
```
