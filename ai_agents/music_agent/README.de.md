## 🚀 Erste Schritte

### **Voraussetzungen**
- Python 3.9+
- PostgreSQL 13+
- Redis 6.0+
- Elasticsearch 7.14+
- Spotify Developer Account

### **Installation**
```bash
# Repository klonen (nur autorisierte Benutzer)
git clone https://github.com/authorized/music-agent.git
cd music-agent

# Abhängigkeiten installieren
pip install -r requirements.txt

# Umgebung konfigurieren
cp .env.example .env
# .env mit Ihren Zugangsdaten bearbeiten

# Datenbank initialisieren
python manage.py migrate

# Services starten
python manage.py runserver
```
