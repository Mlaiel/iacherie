## 🚀 Getting Started

### **Quick Setup**
```python
from backend.ai_agents.compliance_agent import ComplianceAgentManager

# Initialize compliance system
compliance_manager = ComplianceAgentManager()
await compliance_manager.initialize()

# Start compliance monitoring
await compliance_manager.start_monitoring()

# Generate compliance report
report = await compliance_manager.generate_report(
    framework="gdpr",
    period_days=30
)
```

### **Advanced Configuration**
```python
# Custom compliance rules
compliance_config = {
    "gdpr_settings": {
        "consent_expiry_days": 365,
        "data_retention_years": 3,
        "breach_notification_hours": 72
    },
    "monitoring": {
        "real_time_alerts": True,
        "automated_remediation": True,
        "executive_reporting": True
    }
}

agent = ComplianceAgent(config=compliance_config)
```
