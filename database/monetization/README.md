## 💻 Usage Examples

### Revenue Tracking
```python
from backend.database.monetization import RevenueRecord, RevenueAnalytics

# Track revenue from multiple platforms
revenue = RevenueRecord(
    user_id=user_id,
    platform=PlatformType.SPOTIFY,
    revenue_type=RevenueType.STREAMING_ROYALTIES,
    gross_amount=Decimal('150.00'),
    net_amount=Decimal('135.00'),
    currency=Currency.EUR
)

# Generate analytics
analytics = RevenueAnalytics.calculate_user_metrics(
    user_id=user_id,
    timeframe=AnalyticsTimeframe.MONTHLY
)
```

### Licensing Management
```python
from backend.database.monetization import LicenseAgreement, RoyaltyCalculation

# Create licensing agreement
license = LicenseAgreement(
    licensor_user_id=creator_id,
    licensee_user_id=brand_id,
    license_type=LicenseType.SYNCHRONIZATION,
    royalty_type=RoyaltyType.PERCENTAGE,
    royalty_rate_percentage=Decimal('15.00'),
    territories=[Territory.WORLDWIDE]
)

# Calculate royalties
royalty = RoyaltyCalculation.calculate_for_period(
    license_id=license.id,
    period_start=start_date,
    period_end=end_date
)
```

### Contract Management
```python
from backend.database.monetization import Contract, ContractSignature

# Create contract with automated workflow
contract = Contract(
    contract_type=ContractType.LICENSE_AGREEMENT,
    primary_party_id=creator_id,
    secondary_party_id=licensee_id,
    terms_and_conditions=ai_generated_terms,
    payment_terms=payment_schedule
)

# Process digital signature
signature = ContractSignature(
    contract_id=contract.id,
    signer_user_id=signer_id,
    signature_type=SignatureType.DIGITAL,
    signature_hash=secure_hash
)
```
