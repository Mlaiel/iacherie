## 📚 أمثلة الاستخدام

### **🎯 تدريب مصنف المحتوى**
```python
from ml.training import train_ainflue_model, ModelType, TrainingMode

# تدريب نموذج تصنيف المحتوى
result = await train_ainflue_model(
    model_type=ModelType.CONTENT_CLASSIFIER,
    training_mode=TrainingMode.DISTRIBUTED,
    dataset_path="/data/creator_content",
    epochs=50,
    batch_size=64,
    automl_enabled=True,
    distributed=True,
    num_gpus=4
)

print(f"دقة التدريب: {result.final_accuracy:.4f}")
print(f"تأثير الأعمال: {result.business_impact_score:.4f}")
```

### **🚀 أنبوب AutoML**
```python
from ml.training import create_automl_pipeline, ModelType

# إنشاء أنبوب AutoML لتوقع المشاركة
automl = create_automl_pipeline(ModelType.ENGAGEMENT_PREDICTOR)
best_model = await automl.search_optimal_model(
    dataset_path="/data/engagement_data",
    optimization_metric="creator_satisfaction"
)
```

### **🌐 التعلم الفيدرالي**
```python
from ml.training import FederatedLearningEngine

# إعداد التعلم الفيدرالي للتدريب الحافظ للخصوصية
fed_engine = FederatedLearningEngine()
federated_model = await fed_engine.train_collaborative_model(
    participants=["creator_group_1", "creator_group_2"],
    model_type=ModelType.RECOMMENDATION_ENGINE,
    privacy_budget=1.0
)
```
