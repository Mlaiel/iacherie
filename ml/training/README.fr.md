## 📚 EXEMPLES D'UTILISATION

### **🎯 Entraînement Classificateur de Contenu**
```python
from ml.training import train_ainflue_model, ModelType, TrainingMode

# Entraîner modèle de classification de contenu
result = await train_ainflue_model(
    model_type=ModelType.CONTENT_CLASSIFIER,
    training_mode=TrainingMode.DISTRIBUTED,
    dataset_path="/data/creator_content",
    epochs=50,
    batch_size=64,
    automl_enabled=True,
    distributed=True,
    num_gpus=4
)

print(f"Précision d'entraînement: {result.final_accuracy:.4f}")
print(f"Impact business: {result.business_impact_score:.4f}")
```

### **🚀 Pipeline AutoML**
```python
from ml.training import create_automl_pipeline, ModelType

# Créer pipeline AutoML pour prédiction d'engagement
automl = create_automl_pipeline(ModelType.ENGAGEMENT_PREDICTOR)
best_model = await automl.search_optimal_model(
    dataset_path="/data/engagement_data",
    optimization_metric="creator_satisfaction"
)
```
