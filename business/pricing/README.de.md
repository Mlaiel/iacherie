## 🎯 Projektübersicht

Das **Pricing-Modul** ist ein industrielles, KI-gestütztes System für dynamische Preisgestaltung und Umsatzoptimierung, entwickelt für Multi-Format Content Creator. Es bietet umfassende Preisstrategien, Tier-Management und Umsatzmaximierung über alle großen Plattformen wie Spotify, YouTube, Instagram, TikTok, OnlyFans und Patreon.

## 📦 Installation & Setup

### Voraussetzungen
```bash
Python 3.9+
PostgreSQL 13+
Redis 6+
Docker & Docker Compose (optional)
```

### Umgebungs-Setup
```bash
# Repository klonen (nur autorisierter Zugriff)
git clone https://github.com/fahedmlaiel/ia-influencer.git
cd ia-influencer/backend/business/pricing

# Virtuelle Umgebung erstellen
python -m venv pricing_env
source pricing_env/bin/activate  # Linux/Mac
# oder
pricing_env\Scripts\activate  # Windows

# Abhängigkeiten installieren
pip install -r requirements.txt

# Datenbank initialisieren
python -m alembic upgrade head

# Services starten
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

### Docker-Deployment
```bash
# Mit Docker erstellen und ausführen
docker-compose up --build -d

# Gesundheitscheck
curl http://localhost:8000/health
```

## 🚀 API-Nutzungsbeispiele

### Optimale Preisberechnung
```python
import asyncio
from pricing import PricingService, PricingRequest, ContentType, PricingStrategy

# Pricing Service initialisieren
pricing_service = PricingService(...)

# Preisanfrage erstellen
request = PricingRequest(
    content_id="content_123",
    content_type=ContentType.MUSIC_TRACK,
    platform="spotify",
    base_price=9.99,
    pricing_strategy=PricingStrategy.AI_PREDICTED_OPTIMAL,
    tier_level=PricingTier.PROFESSIONAL,
    geographic_market="EU"
)

# Optimale Preisgestaltung berechnen
response = await pricing_service.calculate_pricing("creator_123", request)
print(f"Optimierter Preis: {response.optimized_price}")
print(f"Vertrauen: {response.confidence_score}")
```

### Tier-Empfehlung
```python
# Tier-Empfehlung erhalten
tier_request = TierRecommendationRequest(
    usage_pattern={
        "avg_monthly_uploads": 50,
        "storage_growth_rate": 0.15,
        "collaboration_frequency": 0.3
    },
    content_types=[ContentType.MUSIC_TRACK, ContentType.VIDEO_SHORT],
    target_revenue=Decimal("1000.00")
)

recommendation = await pricing_service.recommend_tier("creator_123", tier_request)
print(f"Empfohlenes Tier: {recommendation.recommended_tier}")
```
