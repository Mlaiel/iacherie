## ⚡ Démarrage Rapide

### Prérequis
- Appareil iOS 14+ ou Android 8+
- Outils de création de contenu professionnels
- Compte plateforme Ainflue

### Installation
```bash
# Cloner le repository
git clone https://github.com/Mlaiel/Ainflue.git

# Naviguer vers le répertoire mobile
cd Ainflue/mobile

# Installer les dépendances
npm install

# Exécuter sur iOS
npx react-native run-ios

# Exécuter sur Android
npx react-native run-android
```

## 🧪 Tests

Exécuter la suite de tests mobile complète :
```bash
cd tests/mobile
python test_mobile_services_complete.py
```
