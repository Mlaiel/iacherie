## ⚡ Schnellstart

### Voraussetzungen
- iOS 14+ oder Android 8+ Gerät
- Professionelle Content-Erstellungstools
- Ainflue-Plattform-Konto

### Installation
```bash
# Repository klonen
git clone https://github.com/Mlaiel/Ainflue.git

# Zum Mobile-Verzeichnis navigieren
cd Ainflue/mobile

# Abhängigkeiten installieren
npm install

# Auf iOS ausführen
npx react-native run-ios

# Auf Android ausführen
npx react-native run-android
```

## 🧪 Testing

Umfassende mobile Test-Suite ausführen:
```bash
cd tests/mobile
python test_mobile_services_complete.py
```
