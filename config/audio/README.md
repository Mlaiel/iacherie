## 🔧 Usage Examples

### Basic Configuration Setup
```python
from backend.config.audio import get_audio_config

# Get comprehensive audio configuration
config = get_audio_config()

# Configure for music production
config.ai_processing_config.enable_neural_mastering = True
config.quality_assurance_config.validation_level = ValidationLevel.PROFESSIONAL

# Set up monetization
config.monetization_config.enable_multi_platform_tracking = True
config.distribution_config.strategy = DistributionStrategy.SIMULTANEOUS_RELEASE
```

### Platform-Specific Optimization
```python
# Configure for Spotify optimization
spotify_config = create_platform_config(DistributionPlatform.SPOTIFY)
spotify_config.loudness_target = -14.0  # LUFS
spotify_config.format_requirements = ["ogg", "mp3", "flac"]

# Configure for YouTube optimization  
youtube_config = create_platform_config(DistributionPlatform.YOUTUBE)
youtube_config.video_optimization = True
youtube_config.thumbnail_generation = True
```

### Real-Time Streaming Setup

# Ultra-low latency configuration
streaming_config = RealTimeConfig()
