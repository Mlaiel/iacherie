## 🚀 **Démarrage Rapide**

### **Installation**

```bash
# Installer les dépendances
pip install -r requirements.txt

# Naviguer vers le répertoire monitoring
cd monitoring/content_lifecycle_monitoring
```

### **Usage Basique**

```python
import asyncio
from index import ContentLifecycleMonitoring

async def main():
    class Config:
        debug = True
    
    # Initialiser le système monitoring enterprise
    monitoring = ContentLifecycleMonitoring(Config())
    await monitoring.initialize()
    
    # Obtenir dashboard enterprise avec tous composants
    dashboard = await monitoring.get_enterprise_dashboard()
    print(f"Santé Système: {dashboard['system_health']['overall_score']:.2f}")
    
    # Tracker parcours contenu spécifique
    content_id = "votre_content_id"
    journey = await monitoring.track_content_journey(content_id)
    print(f"Étapes parcours: {len(journey['component_insights'])}")
    
    # Arrêt propre
    await monitoring.shutdown()

# Exécuter le système monitoring
asyncio.run(main())
```
