## 🛠️ **INSTALLATION & UTILISATION**

### **Prérequis**
```bash
python >= 3.9
pip >= 21.0
```

### **Installation Dépendances**
```bash
pip install -r requirements.txt
pip install -r requirements-monitoring.txt
```

### **Utilisation de Base**
```python
from monitoring.core import get_monitoring_dashboard, start_monitoring

# Démarrer monitoring
await start_monitoring()

# Obtenir dashboard unifié
dashboard = await get_monitoring_dashboard()
print(f"Score Santé: {dashboard['overall_health_score']}")
```

### **Utilisation CLI**
```bash
# Démarrer orchestrateur monitoring
python monitoring/core/index.py start

# Obtenir dashboard monitoring
python monitoring/core/index.py dashboard

# Vérifier statut santé
python monitoring/core/index.py health
```
