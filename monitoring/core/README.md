## 🛠️ **INSTALLATION & USAGE**

### **Prerequisites**
```bash
python >= 3.9
pip >= 21.0
```

### **Dependencies Installation**
```bash
pip install -r requirements.txt
pip install -r requirements-monitoring.txt
```

### **Basic Usage**
```python
from monitoring.core import get_monitoring_dashboard, start_monitoring

# Start monitoring
await start_monitoring()

# Get unified dashboard
dashboard = await get_monitoring_dashboard()
print(f"Health Score: {dashboard['overall_health_score']}")
```

### **CLI Usage**
```bash
# Start monitoring orchestrator
python monitoring/core/index.py start

# Get monitoring dashboard
python monitoring/core/index.py dashboard

# Check health status
python monitoring/core/index.py health
```
