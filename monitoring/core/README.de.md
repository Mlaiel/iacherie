## 🛠️ **INSTALLATION & NUTZUNG**

### **Voraussetzungen**
```bash
python >= 3.9
pip >= 21.0
```

### **Abhängigkeiten Installation**
```bash
pip install -r requirements.txt
pip install -r requirements-monitoring.txt
```

### **Grundlegende Nutzung**
```python
from monitoring.core import get_monitoring_dashboard, start_monitoring

# Monitoring starten
await start_monitoring()

# Einheitliches Dashboard erhalten
dashboard = await get_monitoring_dashboard()
print(f"Gesundheitsscore: {dashboard['overall_health_score']}")
```

### **CLI Nutzung**
```bash
# Monitoring Orchestrator starten
python monitoring/core/index.py start

# Monitoring Dashboard erhalten
python monitoring/core/index.py dashboard

# Gesundheitsstatus prüfen
python monitoring/core/index.py health
```
