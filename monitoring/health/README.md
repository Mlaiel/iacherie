## 🚀 **QUICK START**

### **Installation**

```bash
# Clone the repository
git clone https://github.com/Mlaiel/Ainflue.git
cd Ainflue

# Install dependencies
pip install -r requirements.txt

# Optional dependencies for full functionality
pip install psutil numpy
```

### **Basic Usage**

```python
from monitoring.health import (
    create_health_monitoring_orchestrator,
    CreatorEconomyHealthConfig,
    CreatorTier
)

# Create configuration
config = CreatorEconomyHealthConfig(
    real_time_monitoring=True,
    predictive_analytics=True,
    ai_powered_insights=True
)

# Initialize health monitoring system
orchestrator = await create_health_monitoring_orchestrator(config)

# Get comprehensive health status
health_status = await orchestrator.get_comprehensive_health_status()
print(f"Overall Health: {health_status['overall_status']}")

# Optimize for specific creator tier
optimization_results = await orchestrator.optimize_creator_tier_health(
    CreatorTier.PREMIUM
)

# Shutdown when done
await orchestrator.shutdown()
```

### **Context Manager Usage**

```python
from monitoring.health import health_monitoring_context

async with health_monitoring_context() as orchestrator:
    # Get health status for elite creators
    elite_health = await orchestrator.get_comprehensive_health_status(
        creator_tier=CreatorTier.ELITE
    )
    
    # System automatically shuts down when exiting context
```
