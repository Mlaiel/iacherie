## 📊 **Usage Examples**

### Quick Start - Generate Creator Documentation
```python
import asyncio
from monitoring.documentation import documentation_orchestrator

async def main():
    # Get system status
    status = await documentation_orchestrator.get_system_status()
    print(f"System health: {status.is_healthy}")
    
    # Generate documentation for musician
    docs = await documentation_orchestrator.generate_creator_documentation(
        creator_type="musician",
        creator_id="artist_123",
        language="en",
        include_interactive=True
    )
    
    print(f"Generated {len(docs['sections'])} documentation sections")

# Run example
asyncio.run(main())
```

### Advanced - Multi-Language API Documentation
```python
from monitoring.documentation import APIDocumentationGenerator

async def generate_api_docs():
    generator = APIDocumentationGenerator()
    
    # Generate comprehensive API documentation
    api_package = await generator.generate_complete_api_documentation(
        formats=['openapi_3_0', 'markdown', 'html', 'postman'],
        include_creator_specific=True,
        language='en'
    )
    
    # Export to files
    output_files = await generator.export_documentation(
        api_package,
        output_directory=Path("./docs/api")
    )
    
    print(f"Generated API documentation: {list(output_files.keys())}")
```

### Creator Onboarding Flow
```python
from monitoring.documentation import CreatorOnboardingDocumentationSystem
```

## 🔗 **API Integration**

### REST API Endpoints
```bash
# Get system status
GET /api/v4/documentation/status

# Generate creator documentation
POST /api/v4/documentation/creators/{creator_id}/generate
Content-Type: application/json
{
    "creator_type": "musician",
    "language": "en",
    "include_interactive": true
}

# Get API documentation
GET /api/v4/documentation/api/openapi.yaml

# Track workflow progress
POST /api/v4/documentation/workflows/{workflow_id}/progress
```

### WebSocket Events
```javascript
// Real-time documentation updates
const ws = new WebSocket('wss://api.iacherie.com/v4/documentation/events');

ws.on('documentation_generated', (event) => {
    console.log('New documentation:', event.data);
});

ws.on('onboarding_progress', (event) => {
    console.log('Onboarding update:', event.progress);
});
```
