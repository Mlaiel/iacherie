## 🛠️ Exemples d'Utilisation

### Analyse Intelligence de Base

```python
from monitoring.intelligence import IntelligenceOrchestrator, CreatorType

# Initialiser système intelligence
orchestrator = IntelligenceOrchestrator({
    "ai_providers": ["openai", "anthropic"],
    "analysis_depth": "comprehensive",
    "real_time_monitoring": True
})

# Analyser performance créateur
creator_analysis = await orchestrator.analyze_creator_performance(
    creator_id="creator_123",
    creator_type=CreatorType.MUSICIAN,
    analysis_scope="full"
)

print(f"Score Performance: {creator_analysis.overall_score}")
print(f"Recommandations: {creator_analysis.recommendations}")
```

### Analyse Intelligence Contenu

```python
from monitoring.intelligence import MultiFormatIntelligenceContentAnalyzer, ContentMetadata, ContentFormat

# Initialiser analyseur contenu
analyzer = MultiFormatIntelligenceContentAnalyzer({
    "analysis_depth": "comprehensive",
    "real_time_processing": True
})

# Analyser contenu
content = ContentMetadata(
    content_id="content_456",
    title="Vidéo Musicale Incroyable",
    description="Dernière vidéo musicale avec visuels époustouflants",
    format=ContentFormat.VIDEO,
    file_size=52428800,  # 50MB
    duration=240.0,  # 4 minutes
    tags=["musique", "vidéo", "divertissement"]
)

analysis = await analyzer.analyze_content(content)
print(f"Niveau Qualité: {analysis.quality_level}")
print(f"Score Optimisation: {analysis.overall_score}")
```
