## 📋 أمثلة الاستخدام

### 🎵 **إنشاء ريمكس صوتي**
```python
from remix_generation import get_remix_generation_manager

manager = get_remix_generation_manager()
audio_engine = manager['audio']

remix = audio_engine.create_remix(
    source_tracks=['مقطع1.mp3', 'مقطع2.mp3'],
    style='إلكتروني',
    tempo=128,
    key='دو_كبير',
    duration=180
)
```

### 🎬 **تركيب مشهد فيديو**
```python
video_engine = manager['video']

composition = video_engine.compose_scene(
    source_videos=['مقطع1.mp4', 'مقطع2.mp4'],
    style='سينمائي',
    effects=['تدرج_الألوان', 'انتقالات'],
    duration=60
)
```

### 🖼️ **نقل نمط الصورة**
```python
image_engine = manager['image']

صورة_منمقة = image_engine.apply_style_transfer(
    content_image='صورة.jpg',
    style_reference='نمط_فني.jpg',
    intensity=0.8,
    preserve_colors=True
)
```
