## 📋 EXEMPLES D'UTILISATION

### 🎵 **Création Remix Audio**
```python
from remix_generation import get_remix_generation_manager

manager = get_remix_generation_manager()
audio_engine = manager['audio']

remix = audio_engine.create_remix(
    source_tracks=['piste1.mp3', 'piste2.mp3'],
    style='electronique',
    tempo=128,
    tonalite='Do_majeur',
    duree=180
)
```

### 🎬 **Composition Scène Vidéo**
```python
video_engine = manager['video']

composition = video_engine.compose_scene(
    source_videos=['clip1.mp4', 'clip2.mp4'],
    style='cinematographique',
    effets=['etalonnage_couleur', 'transitions'],
    duree=60
)
```

```python
image_engine = manager['image']

image_stylisee = image_engine.apply_style_transfer(

)
```
