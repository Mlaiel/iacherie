## 🚀 Démarrage Rapide

### Prérequis

```bash
Python 3.12+
FastAPI
SQLAlchemy
Bibliothèques cryptographiques
Frameworks ML (scikit-learn, TensorFlow)
```

### Installation

```bash
# Cloner le repository
git clone https://github.com/Mlaiel/IA Chérie.git

# Naviguer vers le module conformité
cd IA Chérie/security/compliance

# Installer les dépendances
pip install -r requirements.txt

# Initialiser la plateforme conformité
python -m compliance.audit_engine --init
```

### Utilisation de Base

```python
from security.compliance import (
    AuditEngine, 
    GDPRProcessor, 
    SOXComplianceEngine,
    PCIDSSValidator
)

# Initialiser les engines conformité
audit = AuditEngine()
gdpr = GDPRProcessor()
sox = SOXComplianceEngine()
pci = PCIDSSValidator()

# Démarrer monitoring conformité compréhensif
await audit.start_monitoring()
await gdpr.process_data_subject_request(user_id, request_type)
await sox.enforce_financial_controls()
await pci.validate_payment_security()
```
