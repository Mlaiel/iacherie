## 📈 Exemples d'Utilisation

### Workflow de Protection de Contenu
```python
# 1. Protéger nouveau contenu
protection_result = await protect_content(
    user_id="createur123",
    content_path="nouvelle_chanson.mp3",
    protection_level=ProtectionLevel.ENTERPRISE
)

# 2. Surveiller les violations
violations = await detect_violations(
    user_id="createur123",
    content_id=protection_result["content_id"]
)

# 3. Traiter les demandes de retrait
for violation in violations:
    if violation["similarity_score"] > 0.85:
        takedown_result = await protection.process_takedown_request(
            user_id="createur123",
            violation_id=violation["id"]
        )

# 4. Suivre la récupération de revenus
revenue_report = await protection.revenue_tracker.generate_revenue_report(
    user_id="createur123",
    start_date=date(2025, 1, 1),
    end_date=date(2025, 1, 31)
)
```

### Tableau de Bord Temps Réel
```python
# Obtenir données de tableau de bord en direct
dashboard = await protection.get_real_time_dashboard("createur123")

print(f"Violations détectées (24h): {dashboard['real_time_metrics']['violations_detected_24h']}")
print(f"Revenus récupérés: €{dashboard['quick_stats']['total_revenue_recovered']}")
```
