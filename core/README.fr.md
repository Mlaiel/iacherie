## 🔧 **Installation & Configuration**

### **Prérequis**
```bash
Python 3.11+
FastAPI 0.104+
PostgreSQL 14+
Redis 7+
Docker & Docker Compose
```

### **Installation Rapide**
```bash
# Cloner le repository
git clone https://github.com/Mlaiel/Ainflue.git
cd Ainflue/core

# Installer les dépendances
pip install -r requirements.txt

# Configuration de l'environnement
cp .env.example .env
# Éditer .env avec vos configurations

# Démarrage du système
python -m core
```

### **Configuration Docker**
```bash
# Construire et démarrer tous les services
docker-compose up -d

# Vérification de santé
docker-compose ps
```

## 💻 **Utilisation**

### **Exemple d'Utilisation de Base**
```python
from core import (
    creator_multi_format_core,
    ia_processing_core,
    protection_business_core,
    monetization_business_core
)

# Traitement de contenu créateur
content_result = await creator_multi_format_core.process_creator_content(
    creator_id="creator_123",
    content_data={
        "format": "video",
        "file_path": "/path/to/video.mp4",
        "metadata": {"title": "Mon Contenu Génial"}
    }
)

# Analyse IA
ai_analysis = await ia_processing_core.analyze_content(
    content_id=content_result["content_id"],
    analysis_type="comprehensive"
)

# Protection des droits d'auteur
protection_result = await protection_business_core.protect_content(
    content_id=content_result["content_id"],
    protection_level="maximum"
)

# Configuration de monétisation
monetization_setup = await monetization_business_core.setup_monetization(
    creator_id="creator_123",
    content_id=content_result["content_id"],
    monetization_strategies=["subscription", "advertising", "licensing"]
)
```

### **Utilisation Avancée**
```python
# Workflow d'orchestration entreprise
```
