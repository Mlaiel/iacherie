## Exemples d'Utilisation

### Recherche Multi-Plateforme de Base
```python
from backend.data.crawlers import CrawlerManager, CrawlerConfig

# Initialiser le gestionnaire de crawler
manager = CrawlerManager(vector_matcher, max_concurrent_crawlers=5)

# Configurer les plateformes
manager.register_crawler_config('youtube', {
    'api_key': 'votre_cle_api_youtube',
    'rate_limit_delay': 1.0
})

# Rechercher sur les plateformes
results = await manager.search_across_platforms(
    fingerprint_data={
        'search_terms': ['piste musicale', 'nom artiste'],
        'title': 'Titre de Chanson Original',
        'artist': 'Nom Artiste'
    },
    platforms=['youtube', 'instagram', 'tiktok']
)
```

### Monitoring Continu
```python
# Créer une tâche de monitoring
task_id = await manager.create_crawler_task(
    crawler_type='youtube',
    fingerprint_data=fingerprint_data,
    search_config={
        'search_terms': ['contenu protégé par droit d\'auteur'],
        'similarity_threshold': 0.85,
        'max_results': 100
    },
    schedule_config={
        'type': 'interval',
        'interval_minutes': 60
    },
    priority=CrawlerPriority.HIGH,
    callback_url='https://votre-app.com/webhook'
)
```

config = CrawlerConfig(
