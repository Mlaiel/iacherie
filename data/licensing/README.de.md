## 🌟 **SYSTEMÜBERSICHT - LIZENZMANAGEMENT

## 🎯 Überblick
Professionelles Lizenz-Datenmanagement-System für die IA Influencer Agent Plattform, das umfassende Tools für Content-Lizenzierung, Tantiemen-Berechnung, Compliance-Überwachung und automatisierte Umsatzverteilung bereitstellt.

## 🏗️ Geschäftslogik-Ablauf
```
Multi-Format Creator Upload → KI Content Processing → Rechte-Schutz → 
Professionelle SEO-Optimierung → Kollaborations-Matching → Multi-Plattform Distribution → 
Lizenz-Management → Tantiemen-Berechnung → Zahlungsabwicklung → Compliance-Überwachung
```

## 🔄 Nutzungsbeispiele

### Lizenzvertrag erstellen
```python
from backend.data.licensing import LicensingDataManager

# Manager initialisieren
licensing_manager = LicensingDataManager()

# Lizenzvertrag erstellen
license_data = {
    "licensor_id": "user_123",
    "licensee_id": "company_456", 
    "content_id": "content_789",
    "license_type": "sync_licensing",
    "title": "Musiklizenz für kommerzielle Videos",
    "usage_rights": ["commercial", "broadcast", "digital_distribution"],
    "territory": "worldwide",
    "royalty_rate": 15.0,
    "license_fee": 5000.00,
    "start_date": "2025-01-01",
    "end_date": "2030-01-01",
    "currency": "EUR"
}

license_agreement = await licensing_manager.create_license_agreement(
    license_data, user_id
)
```

### Tantiemen berechnen
```python
# Tantiemen für Berichtszeitraum berechnen
usage_data = {
    "total_revenue": 50000.00,
    "total_plays": 1000000,
    "total_streams": 750000,
    "platform_breakdown": {
        "spotify": {"revenue": 25000, "plays": 500000},
        "youtube": {"revenue": 15000, "plays": 300000},
        "apple_music": {"revenue": 10000, "plays": 200000}
    },
    "territory_breakdown": {
        "DE": {"revenue": 30000, "plays": 600000},
        "EU": {"revenue": 15000, "plays": 300000},
        "AT": {"revenue": 5000, "plays": 100000}
    }
}

royalty_calculation = await licensing_manager.calculate_license_royalties(
    license_agreement.id,
    usage_data, 
    ("2025-01-01", "2025-01-31"),
    "percentage"
)
```
