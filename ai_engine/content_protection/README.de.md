## Schnellstart

```python
from ai.content_protection import ContentProtector, ProtectionLevel

# Protector initialisieren
protector = ContentProtector()

# Inhalt schützen
result = await protector.protect_content(
    content_path="./music/song.mp3",
    creator_id="user123",
    protection_level=ProtectionLevel.PREMIUM
)

# Auf Piraterie überwachen
detection_results = await protector.monitor_content(
    content_id=result.protection_id
)
```
