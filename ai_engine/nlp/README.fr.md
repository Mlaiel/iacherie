## Exemples d'Utilisation 💻

### Analyse de Contenu de Base
```python
from backend.ai.nlp.analyzers import ContentAnalysisPipeline

analyzer = ContentAnalysisPipeline()
result = await analyzer.analyze_comprehensive("Votre contenu ici")
```

### Classification Avancée
```python
from backend.ai.nlp.classification import AdvancedContentClassifier

classifier = AdvancedContentClassifier()
classification = await classifier.classify_content(content, platform="instagram")
```

### Génération de Contenu
```python
from backend.ai.nlp.generators import SocialPostGenerator

generator = SocialPostGenerator()
post = await generator.generate_post(prompt, platform="tiktok")
```
