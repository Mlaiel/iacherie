## 🚀 Getting Started

### Installation
```bash
# Install dependencies
pip install -r requirements.txt

# Initialize observability infrastructure  
python -m backend.ai.observability.setup

# Start monitoring services
python -m backend.ai.observability.start_monitoring
```

### Quick Configuration
```python
from backend.ai.observability import ObservabilityManager

# Initialize with business context
obs_manager = ObservabilityManager(
    environment="production",
    business_context="ia_influencer_platform",
    monitoring_level="detailed"
)

# Start comprehensive monitoring
await obs_manager.start_monitoring()
```
