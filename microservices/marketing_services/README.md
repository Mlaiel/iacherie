## 🚀 Quick Start

```python
from microservices.marketing_services import create_marketing_services_manager

# Initialize services
manager = create_marketing_services_manager()
await manager.initialize_all_services()

# Execute marketing campaign
campaign_spec = {
    'campaign_id': 'campaign_001',
    'objectives': ['brand_awareness'],
    'target_creator_types': ['musician', 'influencer'],
    'budget': {'total': 50000},
    'platforms': ['instagram', 'tiktok']
}

result = await manager.execute_marketing_campaign(campaign_spec)
```
