## 🎯 غرض الوحدة

توفر وحدة خدمات الاختبار **خدمات ضمان الجودة والاختبار الآلي على مستوى المؤسسات** لمنصة Ainflue. تنسق هذه الوحدة اختبارات شاملة عبر جميع طبقات الخدمات، وتقدم إمكانيات اختبار الوحدة، اختبار التكامل، التحقق من الأداء، اختبار الأمان وهندسة الفوضى مع موثوقية وتغطية على مستوى المؤسسات.

## 🏗️ المعمارية 

### أنماط الاختبار للمؤسسات
- **تنسيق الاختبار الآلي**: اختبارات موزعة عبر الخدمات المصغرة
- **اختبارات الأداء**: اختبارات الحمولة والتحقق من الأداء
- **اختبارات الأمان**: فحص الثغرات والتحقق من الأمان
- **اختبارات التكامل**: اختبارات التواصل بين الخدمات
- **هندسة الفوضى**: اختبارات المرونة وتحمل الأخطاء
- **اختبارات العقود**: التحقق من عقود API والتحقق منها

### تكامل Service Mesh
- **اكتشاف خدمات الاختبار**: تسجيل خدمات الاختبار التلقائي
- **توزيع الأحمال**: توزيع ذكي لتنفيذ الاختبارات
- **قواطع الدوائر**: تحمل الأخطاء لتبعيات الاختبار
- **التتبع الموزع**: تتبع كامل لتنفيذ الاختبارات

## 🚀 نظرة عامة على الخدمات

### خدمات الاختبار الأساسية
- **`unit_testing_service.py`** - اختبارات الوحدة الآلية لجميع الخدمات
- **`integration_testing_service.py`** - اختبارات التكامل بين الخدمات
- **`performance_testing_service.py`** - اختبارات الحمولة والتحقق من الأداء
- **`security_testing_service.py`** - فحص ثغرات الأمان والاختبارات

### خدمات الاختبار المتقدمة (المؤسسات)
- **`load_testing_service.py`** - إمكانيات اختبار الحمولة عالية الحجم
- **`contract_testing_service.py`** - التحقق من عقود API والاختبارات
- **`chaos_testing_service.py`** - هندسة الفوضى واختبارات المرونة
- **`e2e_testing_service.py`** - اختبارات تدفق العمل الشاملة

## 🔧 الاستخدام في الإنتاج

### تهيئة خدمات الاختبار
```python
from microservices.testing_services import testing_services_module

# تهيئة خدمات الاختبار
await testing_services_module.initialize()

# تشغيل مجموعة الاختبارات الكاملة
test_results = await testing_services_module.run_full_suite()

# الحصول على مقاييس الاختبار
metrics = testing_services_module.get_test_metrics()
```

### خدمة اختبار الوحدة
```python
from microservices.testing_services import UnitTestingService

# اختبارات الوحدة الآلية
unit_service = UnitTestingService()
results = await unit_service.run_service_tests("ai_services")
coverage = await unit_service.get_coverage_report()
```

### خدمة اختبار الأداء
```python
from microservices.testing_services import PerformanceTestingService

# اختبارات الحمولة
perf_service = PerformanceTestingService()
load_results = await perf_service.run_load_test(
    target_service="api_gateway",
    concurrent_users=10000,
    duration_minutes=30
)
```
