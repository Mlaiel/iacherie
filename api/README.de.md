## Architektur
- ASGI FastAPI App mit flacher Verzeichnistiefe (<=3 Ebenen unter `backend/app`)
- Versionierung via `api/v1_router.py`, eingebunden durch `api/router.py` mit `/api/v1/...`
- Core-Module: Konfiguration, DB, Logging, Security
- Domain: SQLAlchemy-Modelle
- Services: Ingestion, Rechte-Schutz, SEO, Collaboration, Distribution
- Schemas: Pydantic-Datenverträge
- Utils: Datei-/Media-Helper

## Start (lokal)
- Python >=3.9, Anforderungen installieren
- Umgebungsvariablen setzen (DATABASE_URL, SECRET_KEY, API_KEYS, etc.)
- ASGI-Server starten

```bash
uvicorn backend.app.asgi:app --host 0.0.0.0 --port 8000
```
