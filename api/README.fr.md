## Architecture
- Application FastAPI ASGI avec profondeur de dossiers limitée (<=3 niveaux sous `backend/app`)
- Versionnement via `api/v1_router.py` inclus par `api/router.py` exposant `/api/v1/...`
- Core: configuration, DB, logging, sécurité
- Domaine: modèles SQLAlchemy
- Services: ingestion, protection, SEO, collaboration, distribution
- Schémas: contrats Pydantic
- Utils: utilitaires fichiers/médias

## Démarrage (local)
- Python >=3.9, installer les dépendances
- Définir les variables d’environnement (DATABASE_URL, SECRET_KEY, API_KEYS, etc.)
- Lancer le serveur ASGI

```bash
uvicorn backend.app.asgi:app --host 0.0.0.0 --port 8000
```
