## 🚀 Quick Start

### Prerequisites
- Node.js 18.0.0 or higher
- npm or yarn package manager
- Modern web browser

### Installation
```bash
# Clone the repository
git clone https://github.com/Mlaiel/Ainflue.git

# Navigate to frontend directory
cd Ainflue/frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

### Development
```bash
# Run in development mode
npm run dev

# Run type checking
npm run type-check

# Run linting
npm run lint

# Run tests
npm run test

# Run tests with coverage
npm run test:coverage
```

### Production
```bash
# Build for production
npm run build

# Start production server
npm run start
```

## 🏗️ Architecture

This frontend follows a professional 4-level architecture designed for scalability and maintainability:

### Level 1: Core (`/core/`)
- **Configuration:** App, API, and Security settings
- **Types:** TypeScript interfaces and type definitions
- **Constants:** Application-wide constants
- **Enums:** System enumerations

### Level 2: Business (`/business/`)
- **Content:** Upload management and processing
- **Protection:** Fingerprinting and copyright management
- **Monetization:** Revenue streams and marketplace
- **Collaboration:** Matching and workflow systems
- **Gamification:** Achievements and social features
- **Distribution:** Multi-platform distribution

### Level 3: Presentation (`/presentation/`)
- **Components:** Reusable UI components
- **Layouts:** Application layouts
- **Pages:** Route-specific pages
- **Hooks:** Custom React hooks
- **Context:** React context providers

### Level 4: Infrastructure (`/infrastructure/`)
- **API:** HTTP client and services
- **Storage:** Local and cloud storage
- **Security:** Authentication and encryption
- **Monitoring:** Metrics and logging
- **Utils:** Utility functions

## 🛠️ Technology Stack

- **Framework:** Next.js 14 with TypeScript
- **Styling:** Tailwind CSS with Material-UI components
- **State Management:** Redux Toolkit with Zustand
- **API Client:** Axios with custom interceptors
- **Form Handling:** React Hook Form with Zod validation
- **Animation:** Framer Motion
- **Testing:** Jest with React Testing Library
- **Internationalization:** i18next with react-i18next
