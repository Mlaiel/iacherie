## 🚀 Getting Started

### Installation & Setup
```bash
# Clone the repository
git clone https://github.com/fahed-mlaiel/ainflue-seo-engine.git
cd ainflue-seo-engine

# Install dependencies
pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Edit .env with your configuration

# Initialize SEO engine
python -m seo_engine.setup
```

### Basic Usage
```python
from seo_engine import SEOContentEngine, SEOIntelligenceEngine

# Initialize SEO engines
content_engine = SEOContentEngine()
intelligence_engine = SEOIntelligenceEngine()

# Optimize content for SEO
result = await content_engine.optimize_content(
    content="Your content here",
    content_type=ContentType.ARTICLE,
    target_keywords=["your", "target", "keywords"]
)

# Analyze SEO intelligence
intelligence = await intelligence_engine.analyze_seo_intelligence(
    domain="yourdomain.com",
    target_keywords=["your", "keywords"],
    competitors=["competitor1.com", "competitor2.com"]
)
```
