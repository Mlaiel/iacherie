## 🚀 Schnellstart

### Installation & Setup
```bash
# Repository klonen
git clone https://github.com/fahed-mlaiel/ainflue-seo-engine.git
cd ainflue-seo-engine

# Dependencies installieren
pip install -r requirements.txt

# Environment konfigurieren
cp .env.example .env
# .env mit Ihrer Konfiguration bearbeiten

# SEO Engine initialisieren
python -m seo_engine.setup
```

### Grundlegende Verwendung
```python
from seo_engine import SEOContentEngine, SEOIntelligenceEngine

# SEO Engines initialisieren
content_engine = SEOContentEngine()
intelligence_engine = SEOIntelligenceEngine()

# Content für SEO optimieren
result = await content_engine.optimize_content(
    content="Ihr Content hier",
    content_type=ContentType.ARTICLE,
    target_keywords=["ihre", "ziel", "keywords"]
)

# SEO Intelligence analysieren
intelligence = await intelligence_engine.analyze_seo_intelligence(
    domain="ihredomain.com",
    target_keywords=["ihre", "keywords"],
    competitors=["konkurrent1.com", "konkurrent2.com"]
)
```
