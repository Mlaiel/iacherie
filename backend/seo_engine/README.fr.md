## 🚀 Démarrage Rapide

### Installation & Configuration
```bash
# Cloner le repository
git clone https://github.com/fahed-mlaiel/ainflue-seo-engine.git
cd ainflue-seo-engine

# Installer dépendances
pip install -r requirements.txt

# Configurer environnement
cp .env.example .env
# Éditer .env avec votre configuration

# Initialiser moteur SEO
python -m seo_engine.setup
```

### Utilisation Basique
```python
from seo_engine import SEOContentEngine, SEOIntelligenceEngine

# Initialiser moteurs SEO
content_engine = SEOContentEngine()
intelligence_engine = SEOIntelligenceEngine()

# Optimiser contenu pour SEO
result = await content_engine.optimize_content(
    content="Votre contenu ici",
    content_type=ContentType.ARTICLE,
    target_keywords=["vos", "mots-clés", "cibles"]
)

# Analyser intelligence SEO
intelligence = await intelligence_engine.analyze_seo_intelligence(
    domain="votredomaine.com",
    target_keywords=["vos", "mots-clés"],
    competitors=["concurrent1.com", "concurrent2.com"]
)
```
