## 🚀 Démarrage Rapide

### **Prérequis**
```bash
- Python 3.12+
- Docker & Docker Compose
- PostgreSQL 15+
- Redis 7+
- Kubernetes (pour déploiement production)
```

### **Configuration Développement**
```bash
# Cloner le repository
git clone https://github.com/Mlaiel/Ainflue.git
cd Ainflue/backend

# Créer environnement virtuel
python -m venv venv
source venv/bin/activate  # Sur Windows: venv\Scripts\activate

# Installer dépendances
pip install -r requirements.txt
pip install -r requirements-dev.txt

# Configurer variables environnement
cp .env.example .env
# Éditer .env avec votre configuration

# Initialiser base données
python -m alembic upgrade head

# Démarrer services développement
docker-compose -f docker-compose.dev.yml up -d

# Lancer serveur backend
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### **Déploiement Production**
```bash
# Construire et déployer avec Docker
docker build -t ainflue-backend .
docker-compose -f docker-compose.prod.yml up -d

# Déployer sur Kubernetes
kubectl apply -f k8s/backend/
kubectl get pods -n ainflue-backend

# Surveiller déploiement
kubectl logs -f deployment/ainflue-backend -n ainflue-backend
```
