## Installation

### Voraussetzungen
```bash
# Python 3.9 oder höher
python --version

# Erforderliche Systempakete
sudo apt-get update
sudo apt-get install ffmpeg libsm6 libxext6 libfontconfig1 libxrender1
```

### Installationsschritte
```bash
# Repository klonen
git clone https://github.com/Mlaiel/Ainflue.git
cd Ainflue/backend/media

# Abhängigkeiten installieren
pip install -r requirements.txt

# Optionale KI-Abhängigkeiten installieren
pip install torch torchvision torchaudio
pip install transformers clip-by-openai librosa

# Konfiguration einrichten
cp config.example.py config.py
# config.py mit Ihren Einstellungen bearbeiten
```

### Umgebungskonfiguration
```bash
# Umgebungsdatei erstellen
cat > .env << EOF
MEDIA_STORAGE_PATH=/pfad/zu/media/storage
REDIS_URL=redis://localhost:6379
DATABASE_URL=postgresql://user:password@localhost/media_db
AI_MODEL_CACHE=/pfad/zu/model/cache
ENABLE_GPU_ACCELERATION=true
EOF
```

## Schnellstart

### Grundlegende Medienverarbeitung
```python
from backend.media import MediaGenerator, ContentEnhancementAI

# Media Generator initialisieren
generator = MediaGenerator()

# Video-Content generieren
video_result = await generator.generate_video({
    "prompt": "Erstelle ein Marketing-Video über nachhaltige Energie",
    "duration": 60,
    "style": "professionell",
    "resolution": "1080p"
})

# Content-Qualität verbessern
enhancer = ContentEnhancementAI()
enhanced_result = await enhancer.enhance_content_auto(video_result)
```

### Echtzeit-Kollaboration
```python
from backend.media import CollaborationEngine

# Kollaborationssitzung starten
engine = CollaborationEngine()
session_id = await engine.create_session({
    "content_id": "video_123",
    "content_type": "video",
    "created_by": "user_123"
})

# Kollaboration beitreten
await engine.join_session(session_id, {
    "user_id": "editor_456",
    "username": "Jane Editor"
})
```

### Content-Klassifizierung
```python
from backend.media import ContentClassificationAI

# Content automatisch klassifizieren
classifier = ContentClassificationAI()
classification = await classifier.classify_content_auto({
    "text": "Wie man ein erfolgreiches Startup aufbaut",
    "file_info": {"duration": 300, "format": "mp4"},
    "visual_analysis": {"detected_objects": ["person", "office"]}
})

print(f"Genre: {classification['primary_genre']}")
print(f"Qualitätswert: {classification['quality_score']}")
```
