## 🚀 Démarrage Rapide

### Prérequis
- Docker & Docker Compose
- Cluster Kubernetes (local ou cloud)
- Terraform >= 1.0
- Ansible >= 2.9

### Installation
```bash
# Cloner le dépôt
git clone https://github.com/Mlaiel/Ainflue.git
cd Ainflue/infrastructure

# Initialiser Terraform
terraform init

# Déployer infrastructure
terraform plan
terraform apply

# Configurer Kubernetes
kubectl apply -f k8s/

# Installer stack monitoring
helm install monitoring ./charts/monitoring
```

### Configuration
```yaml
# infrastructure/config/production.yaml
cloud_providers:
  aws:
    region: eu-west-1
    instance_types: [t3.medium, t3.large]
  gcp:
    region: europe-west1
    machine_types: [e2-medium, e2-standard-4]
  azure:
    region: West Europe
    vm_sizes: [Standard_B2s, Standard_B4ms]

autoscaling:
  min_nodes: 3
  max_nodes: 100
  target_cpu: 70
  target_memory: 80
```
