# 🧪 منصة Ainflue - بنية اختبار Docker التحتية

**بنية اختبار على مستوى المؤسسة لتحوية منصة مؤثر الذكاء الاصطناعي. مجموعة اختبارات شاملة مع متطلب تغطية 95%+ تدعم أكثر من 80 خدمة مصغرة.**

---

## 📋 نظرة عامة

توفر وحدة الاختبار هذه بنية اختبار شاملة على مستوى المؤسسة لمنصة Ainflue AI Influencer. تدعم البنية اختبارات شاملة عبر أكثر من 80 خدمة مصغرة مع تنفيذ اختبار آلي وتحقق الأداء وفحص الأمان وهندسة الفوضى.

### 🎯 تدفق منطق الأعمال
```
منشئ المحتوى (موسيقي/مدون/مصور/مؤثر/كوميدي) 
    ↓
رفع متعدد التنسيقات (صوت/فيديو/صورة/نص) 
    ↓
حماية حقوق الطبع والنشر AI + العلامة المائية + البصمة
    ↓
تحسين محركات البحث المهني + التحسين + البيانات الوصفية المحسنة
    ↓
مطابقة التعاون AI + التلعيب + التحديات
    ↓
التوزيع متعدد المنصات + التحسين الخاص بالمنصة
    ↓
بنية اختبار شاملة ← هذه الوحدة
```

## 🏗️ نظرة عامة على البنية

### 📊 **خدمات الاختبار (12 حاوية)**

#### **خدمات الاختبار الأساسية (4 حاويات)**
- **Test Runner** - محرك تنفيذ الاختبار الرئيسي
- **Integration Tester** - التحقق متعدد الخدمات
- **Performance Tester** - اختبار الحمولة والضغط  
- **Security Tester** - اختبار الثغرات والاختراق

#### **خدمات الاختبار المتخصصة (8 حاويات)**
- **Load Tester** - اختبار حمولة عالية الحجم
- **Stress Tester** - اختبار نقطة انكسار النظام
- **Chaos Engineering** - حقن الأعطال واختبار المرونة
- **E2E Tester** - اختبار من البداية للنهاية
- **Smoke Tester** - التحقق من الوظائف الأساسية
- **Regression Tester** - اختبار الانحدار الآلي

## 🚀 البداية السريعة

### المتطلبات الأساسية
- Docker 24.0+
- Docker Compose 2.0+
- 16GB+ ذاكرة الوصول العشوائي (للاختبارات الشاملة)
- 4+ أنوية المعالج

### تشغيل الاختبارات

```bash
# تشغيل جميع الاختبارات
docker-compose -f docker-compose.testing.yml up --abort-on-container-exit

# تشغيل نوع اختبار محدد
docker-compose -f docker-compose.testing.yml up test_runner
docker-compose -f docker-compose.testing.yml up performance_tester
docker-compose -f docker-compose.testing.yml up security_tester

# اختبارات مع معاملات مخصصة
docker run --rm ainflue/test-runner:latest pytest --cov --cov-report=html

# اختبار الأداء مع حمولة مخصصة
docker run --rm ainflue/performance-tester:latest locust --users=500 --spawn-rate=25
```
