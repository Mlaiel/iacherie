### 🚀 **Démarrage Rapide**

#### Installation

```bash
pip install iacherie-audio-templates
```

#### Utilisation Basique

```python
from templates.audio import AudioTemplateFactory

# Initialiser factory
factory = AudioTemplateFactory()

# Créer template composition musicale
composition = await factory.create_template(
    "music_composition_template",
    config={
        "genre": "pop",
        "tempo": 120,
        "duration": 30.0
    }
)

# Générer musique
result = await composition.process_audio()
print(f"Composition générée : {result.composition_metadata['title']}")
```
