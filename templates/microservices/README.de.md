## 🚀 Schnellstart

### **1. Creator Service erstellen**

```python
from templates.microservices.creator_economy import CreatorServiceTemplate
from templates.microservices.creator_economy.creator_service_template import CreatorServiceConfig

# Service konfigurieren
config = CreatorServiceConfig(
    database_url="postgresql://user:pass@localhost/creators",
    redis_url="redis://localhost:6379",
    ai_service_url="http://ai-service:8001",
    verification_service_url="http://verification:8002",
    notification_service_url="http://notifications:8003"
)

# Service erstellen und starten
creator_service = CreatorServiceTemplate(config)
await creator_service.start()
```

### **2. Message Queue einrichten**

```python
from templates.microservices.communication import MessageQueueTemplate
from templates.microservices.communication.message_queue_template import MessageQueueConfig

# Message Queue konfigurieren
config = MessageQueueConfig(
    redis_url="redis://localhost:6379",
    stream_name="content_processing",
    consumer_group="processors",
    consumer_name="processor_1"
)

# Message Queue erstellen
message_queue = MessageQueueTemplate(config)
await message_queue.start()

# Handler registrieren
await message_queue.register_handler("content.uploaded", handle_content_upload)
await message_queue.register_handler("ai.processing.completed", handle_ai_completion)
```

## 🚀 Deployment

### **Docker Deployment**

```yaml
version: '3.8'
services:
  creator-service:
    image: ainflue/creator-service:latest
    environment:
      - DATABASE_URL=postgresql://postgres:password@db:5432/creators
      - REDIS_URL=redis://redis:6379
    depends_on:
      - db
      - redis
    ports:
      - "8001:8000"
```

### **Kubernetes Deployment**

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: creator-service
spec:
  replicas: 3
  selector:
    matchLabels:
      app: creator-service
  template:
    metadata:
      labels:
        app: creator-service
    spec:
      containers:
      - name: creator-service
        image: ainflue/creator-service:latest
        ports:
        - containerPort: 8000
```
