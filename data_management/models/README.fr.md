## 📋 Exemples d'Utilisation

### Créer un Modèle de Contenu
```python
from backend.data_management.models import ContentModel, ContentType

content = ContentModel(
    creator_id="creator_123",
    tenant_id="tenant_456", 
    content_type=ContentType.AUDIO,
    filename="ma_chanson.mp3"
)

# Mettre à jour le statut de traitement
content.update_status(ContentStatus.PROCESSING)

# Calculer l'engagement
engagement_rate = content.calculate_engagement_rate()
```

### Gestion de Profil Créateur
```python
from backend.data_management.models import CreatorModel, CreatorType

creator = CreatorModel(
    user_id="user_789",
    tenant_id="tenant_456",
    email="artiste@example.com",
    creator_type=CreatorType.MUSICIAN
)

# Calculer le niveau créateur
tier = creator.calculate_creator_tier()

# Mettre à jour les analytiques
creator.update_analytics({
    "content_count": 25,
    "view_count": 50000,
    "engagement_rate": 5.2
})
```
