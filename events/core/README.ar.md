## 🚀 نظرة عامة للمؤسسات

**وحدة الأحداث الأساسية** هي البنية التحتية الأساسية لمعالجة الأحداث في منصة Ainflue، المصممة خصيصاً لمنشئي المحتوى متعدد التنسيقات (الموسيقيين، المدونين، المصورين، المؤثرين، الكوميديين). يوفر هذا النظام الصناعي فائق التطور إدارة أحداث على مستوى المؤسسات ومعالجة في الوقت الفعلي وتنسيق منطق الأعمال.

### 🎯 **تدفق منطق الأعمال**
```
المستخدم (منشئ متعدد التنسيقات) → رفع المحتوى → معالجة أحداث الذكاء الاصطناعي → 
أحداث الحماية → أحداث تحسين محركات البحث → أحداث التعاون → أحداث التوزيع
```

## 🏗️ **مكونات البنية الأساسية**

### **البنية التحتية الأساسية (11 ملف)**
- `__init__.py` - تهيئة وتصديرات الوحدة
- `base_event.py` - فئة الحدث الأساسية الجوهرية
- `base_event_handler.py` - البنية التحتية الأساسية لمعالج الأحداث
- `event_dispatcher.py` - نظام التوجيه وإرسال الأحداث
- `event_lifecycle.py` - إدارة دورة حياة الأحداث
- `event_priority.py` - معالجة الأحداث بناءً على الأولوية
- `event_status.py` - نظام تتبع حالة الأحداث
- `exceptions.py` - إدارة أخطاء شاملة
- `redis.py` - تكامل Redis لتدفق الأحداث

### **أنواع أحداث الأعمال (3 ملفات)**
- `content_events.py` - أحداث رفع/معالجة المحتوى
- `ai_processing_events.py` - أحداث تحليل وتحسين الذكاء الاصطناعي
- `monetization_events.py` - أحداث الإيرادات والمدفوعات

## 🔧 **أمثلة الاستخدام**

### **حدث معالجة المحتوى**
```python
from events.core import ContentUploadEvent, EventDispatcher

# إنشاء حدث رفع المحتوى
event = ContentUploadEvent(
    creator_id="musician_123",
    creator_type="musician",
    content_type="audio",
    content_data={
        "file_path": "/uploads/song.mp3",
        "metadata": {"genre": "electronic", "duration": 240}
    }
)

# إرسال حدث للمعالجة
await EventDispatcher.dispatch(event)
```

### **حدث معالجة الذكاء الاصطناعي**
```python
from events.core import AIAnalysisEvent

# إنشاء حدث تحليل الذكاء الاصطناعي
ai_event = AIAnalysisEvent(
    content_id="content_456",
    analysis_type="fingerprinting",
    ai_model="audio_fingerprint_v2",
    processing_options={"quality": "high"}
)

await EventDispatcher.dispatch(ai_event)
```

### **حدث تحقيق الدخل**
```python
from events.core import RevenueGeneratedEvent

# إنشاء حدث الإيرادات
revenue_event = RevenueGeneratedEvent(
    creator_id="creator_789",
    revenue_type="streaming",
    amount=125.50,
    currency="USD",
    platform="spotify"
)

await EventDispatcher.dispatch(revenue_event)
```
