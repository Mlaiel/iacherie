## 🚀 Verwendung

### Performance-Monitoring

```python
from payment.analytics import PaymentPerformanceMonitor

monitor = PaymentPerformanceMonitor()

# Zahlungsleistung überwachen
result = await monitor.monitor_payment_performance({
    'response_time': 75.0,
    'throughput': 1200.0,
    'error_rate': 0.3,
    'availability': 99.8
})

print(f"Performance-Score: {result['performance_score']}")
```

### Kostenoptimierung

```python
from payment.analytics import CostOptimizationAnalyzer

analyzer = CostOptimizationAnalyzer()

# Zahlungskosten analysieren
result = await analyzer.analyze_payment_costs({
    'volume': 5000,
    'amount': 250000,
    'provider': 'stripe'
})

print(f"Potenzielle Einsparungen: ${result['savings_analysis']['total_monthly_savings']}")
```

### Transaction Intelligence

```python
from payment.analytics import TransactionIntelligence

intelligence = TransactionIntelligence()

# Transaktionsmuster analysieren
patterns = await intelligence.analyze_transaction_patterns(transactions)
anomalies = await intelligence.detect_transaction_anomalies(transactions)

print(f"Muster gefunden: {len(patterns)}")
print(f"Anomalien erkannt: {len(anomalies)}")
```
