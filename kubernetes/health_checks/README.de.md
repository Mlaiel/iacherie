## 📈 Anwendungsbeispiele

### Basis-Gesundheitscheck

```python
from backend.deployment.health_checks import ComprehensiveHealthChecker

# Gesundheitschecker initialisieren
health_checker = ComprehensiveHealthChecker(config)

# Umfassenden Gesundheitscheck durchführen
health_summary = await health_checker.check_platform_health()

print(f"Plattform-Gesundheit: {health_summary.overall_status}")
print(f"Gesunde Services: {health_summary.healthy_services}")
print(f"Kritische Probleme: {health_summary.critical_issues}")
```

### Metriken-Sammlung

```python
from backend.deployment.health_checks import HealthMetricsCollector

# Metriken-Sammler initialisieren
metrics_collector = HealthMetricsCollector(config)

# Gesundheitsmetriken sammeln
health_results = await health_checker.check_all_services()
await metrics_collector.collect_health_metrics(health_results)

# Metriken-Zusammenfassung abrufen
summary = await metrics_collector.get_metrics_summary(time_range_hours=1)
```

### Trendanalyse

```python
# Gesundheitstrends analysieren
trend = await metrics_collector.analyze_health_trends(
    service_name="database_service",
    metric_name="response_time_ms",
    hours=24
)

print(f"Trend-Richtung: {trend.trend_direction}")
print(f"Vorhersage-Vertrauen: {trend.prediction_confidence:.2%}")
```
