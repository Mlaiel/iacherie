# 🗜️ وحدة الذكاء المتقدم للضغط

**ضغط الوسائط المتعددة على مستوى المؤسسة مع التحسين المدعوم بالذكاء الاصطناعي لمنصة Ainflue**

## نظرة عامة

توفر وحدة الذكاء للضغط قدرات ضغط وسائط متعددة متطورة مع التحسين المدعوم بالذكاء الاصطناعي، وتدعم جميع تنسيقات الصوت والفيديو والصور الرئيسية. تجمع هذه الوحدة خوارزميات الضغط التقليدية مع التعلم الآلي لتقليل حجم الملف الأمثل مع الحفاظ على الجودة.

## المميزات

### 🎵 ضغط الصوت
- **الترميزات**: MP3, AAC, FLAC, Opus, OGG, WAV, M4A
- **ملفات الجودة**: البودكاست، الموسيقى القياسية، الموسيقى عالية الدقة، البث، الجوال
- **تحسين الذكاء الاصطناعي**: اختيار معدل البت التلقائي بناءً على تحليل المحتوى
- **المعالجة المجمعة**: ضغط متزامن مع حدود قابلة للتكوين

### 🎬 ضغط الفيديو
- **الترميزات**: H.264, H.265/HEVC, AV1, VP9, VP8, MPEG-4
- **الحاويات**: MP4, WebM, AVI, MOV, MKV
- **تحسين المنصة**: YouTube, Instagram, TikTok, Web, Mobile
- **المميزات المتقدمة**: ترميز التمريرتين، إعداد البث التكيفي

### 🖼️ ضغط الصور
- **تنسيقات الجيل الجديد**: WebP, AVIF, HEIF, JPEG XL
- **التنسيقات التقليدية**: JPEG, PNG, BMP, TIFF
- **التحسين الذكي**: اختيار الضغط الواعي للمحتوى
- **التحجيم المتجاوب**: تغيير الحجم التلقائي لأحجام الشاشة المختلفة

## البداية السريعة

```python
from multimedia.compression import (
    AudioCompressionEngine,
    VideoCompressionEngine,
    ImageCompressionEngine,
    AdaptiveCompressionEngine
)

# ضغط الصوت مع ملف محدد مسبقاً
audio_engine = AudioCompressionEngine()
result = await audio_engine.compress_audio(
    "input.wav", 
    "output.mp3", 
    profile="podcast"
)

# ضغط الفيديو لـ YouTube
video_engine = VideoCompressionEngine()
result = await video_engine.compress_video(
    "input.mov",
    "output.mp4", 
    profile="youtube_1080p"
)

# ضغط الصور الذكي
image_engine = ImageCompressionEngine()
result = await image_engine.compress_image(
    "input.jpg",
    "output.webp",
    profile="web_optimized"
)
```

## ملفات الضغط

### ملفات الصوت
- **البودكاست**: 64 kbps MP3، محسن للمحتوى الصوتي
- **الموسيقى القياسية**: 256 kbps AAC، توازن الجودة/الحجم
- **الموسيقى عالية الدقة**: FLAC بدون فقدان، جودة عشاق الصوت
- **البث**: 128 kbps Opus، محسن للبث المباشر
- **الجوال**: 96 kbps AAC، واعي بعرض النطاق

### ملفات الفيديو
- **YouTube 1080p**: H.264، 8 Mbps، محسن لرفع YouTube
- **YouTube 4K**: H.265، 25 Mbps، محتوى 4K لـ YouTube
- **Instagram Story**: H.264، 3.5 Mbps، تنسيق عمودي
- **TikTok**: H.264، 2.5 Mbps، عمودي محسن للجوال
- **البث عبر الويب**: VP9، 4 Mbps، متوافق مع المتصفح

## مقاييس الأداء

- **ضغط الصوت**: حتى 85% تقليل الحجم مع فقدان جودة أدنى
- **ضغط الفيديو**: حتى 50% تقليل الحجم مع H.265 مقابل H.264
- **ضغط الصور**: حتى 70% تقليل الحجم مع AVIF مقابل JPEG
- **سرعة المعالجة**: ضغط معجل GPU حتى 10 مرات أسرع

## دعم المتصفح

### تنسيقات الصور
- **WebP**: 95%+ دعم المتصفح
- **AVIF**: 75%+ دعم المتصفح (نمو سريع)
- **HEIF**: محدود (Safari فقط)
- **JPEG XL**: تجريبي

### تنسيقات الفيديو
- **H.264**: دعم عالمي
- **H.265**: 80%+ دعم المتصفح الحديث
- **AV1**: 75%+ دعم المتصفح
- **VP9**: 90%+ دعم المتصفح
